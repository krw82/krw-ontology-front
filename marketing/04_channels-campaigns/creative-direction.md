# KRW Ontology 크리에이티브 방향성

*작성일: 2026-05-23*

## 요약

KRW Ontology의 모든 마케팅 크리에이티브는 "근거 경로가 보이는 리서치"를 시각적으로 증명하는 방향으로 설계한다. 다크 UI 기반의 제품 스크린샷, 근거 경로 시각화, 공시 문장 인용을 핵심 시각 자산으로 활용한다.

**핵심 원칙:** 보여주라, 말하지 마라. 제품이 근거를 보여주듯, 크리에이티브도 가치를 보여준다.

### 1.2 타이포그래피

### 1.3 디자인 원칙

1. **근거 우선:** 모든 크리에이티브에 근거 경로 또는 인용 시각 요소 포함
2. **다크 테마 일관성:** 제품 UI와 동일한 다크 테마를 모든 마케팅 자산에 적용
3. **정보 밀도:** 충분한 여백을 유지하면서 핵심 정보를 밀도 있게 배치
4. **신뢰도:** 과장된 그래픽 효과 지양. 깔끔하고 정밀한 시각 언어

## 2. 제품 스크린샷 가이드라인

### 2.1 캡처 기준

- **해상도:** Retina (2x) 최소 1440x900 픽셀
- **브라우저:** 크롬, 주소창/탭바 제외 (또는 깔끔한 브라우저 프레임)
- **데이터:** 실제 제품 데이터 사용 (목업/더미 데이터 금지)
- **배경:** 제품 다크 테마 그대로 캡처

### 2.2 필수 스크린샷 세트

| 스크린샷 | 용도 | 캡처 포인트 |
|----------|------|------------|
| 홈페이지 전체 | 랜딩, 디렉토리 | 히어로 섹션 + CTA |
| 회사 목록 | 디렉토리, 광고 | 지원 회사 리스트 |
| 채팅 인터페이스 | 데모, 광고 | 질문 입력 + 답변 진행 |
| 답변 완료 | 핵심 자산 | 답변 + 인용 + 근거 경로 |
| 근거 경로 확장 | 핵심 자산 | 인용 클릭 후 원문 표시 |
| 모바일 채팅 | 모바일 광고 | 모바일 UI 전체 화면 |

### 2.3 스크린샷 보정 규칙

- **콘트라스트 조정:** 배경과 텍스트 대비 강화 (원본보다 5~10% 증가)
- **블러 처리:** 개인 정보, 실제 티커 외의 식별 정보는 블러
- **하이라이트:** 핵심 요소(근거 경로, 인용)에 악센트 컬러 테두리 추가
- **프레임:** 다크 그레이 라운드 프레임 (12px radius) + 미묘한 그림자

### 2.4 기기 목업

- **데스크톱:** MacBooks (실버/스페이스그레이), 깔끔한 배경
- **모바일:** iPhone 15 Pro (티타늄 블루/블랙), 실제 제품 화면
- **프레임 소스:** Figma 디바이스 프레임 또는 CleanShot X

## 4. 캐러셀 디자인 가이드

### 4.1 LinkedIn/Instagram 캐러셀 구조

**5슬라이드 기본 구조:**
```
슬라이드 1 (표지): 제목 + 시각 훅
슬라이드 2: 문제 정의
슬라이드 3: 해결책 소개
슬라이드 4: 제품 시연/예시
슬라이드 5: CTA
```

**8슬라이드 심층 구조:**
```
슬라이드 1 (표지): 제목 + 티커 심볼
슬라이드 2: 배경/왜 중요한지
슬라이드 3~4: 공시에서 발견한 데이터
슬라이드 5~6: 근거 분석 + 인용
슬라이드 7: KRW Ontology 스크린샷
슬라이드 8: 요약 + CTA
```

### 4.2 캐러셀 디자인 규칙

- **사이즈:** 1080×1080px (Instagram/LinkedIn 공통)
- **배경:** #0A0F1E (다크 네이비)
- **텍스트:** 한 슬라이드당 최대 50자 (한글 기준)
- **시각 요소:** 스크린샷, 아이콘, 차트, 인용 블록
- **슬라이드 전환:** 오른쪽 화살표 또는 "넘기기" 시각 힌트
- **일관성:** 동일 컬러 팔레트, 폰트, 여백 규칙

### 4.3 캐러셀 템플릿 아이디어

1. **"10-K 분석 체크리스트"** — 슬라이드당 1섹션 (Risk Factors, MD&A, Financial Statements, etc.)
2. **"AI 리서치 vs 일반 요약"** — 비교형 슬라이드
3. **"질문 템플릿 5선"** — 슬라이드당 1질문 카테고리
4. **"공시에서 발견한 숨은 인사이트"** — 인용 + 해석 스타일
5. **"근거 경로가 보이면 다릅니다"** — Before/After 비교

## 7. 데모 영상 스크립트

### 7.1 60초 제품 데모 (유튜브 인스킵 광고 / 홈페이지 히어로)

```
[0:00~0:03] 훅
- 화면: 다크 배경에 텍스트 타이핑 애니메이션
- 텍스트: "10-K를 다 읽을 시간이 없다면?"
- 내레이션: "10-K를 다 읽을 시간이 없다면?"

[0:03~0:10] 문제
- 화면: 긴 공시 문서 스크롤 + 시계 아이콘
- 텍스트: "평균 10-K는 100페이지 이상"
- 내레이션: "미국 기업 공시는 평균 100페이지가 넘습니다. 중요한 근거를 찾기 어렵죠."

[0:10~0:25] 솔루션 — 질문
- 화면: KRW Ontology 채팅 인터페이스, 질문 입력
- 텍스트: "AMZN 클라우드 이익률이 왜 바뀌었는지 근거와 함께 정리해줘"
- 내레이션: "KRW Ontology에 질문하세요. AMZN 클라우드 이익률 변화를 근거와 함께 정리해줘."

[0:25~0:45] 솔루션 — 답변 + 근거
- 화면: 답변 생성 애니메이션 → 인용 하이라이트 → 근거 경로 확장
- 내레이션: "답변에는 공시 원문 인용이 포함됩니다. 근거 경로를 클릭하면 어떤 문장에서 나온 말인지 바로 확인할 수 있습니다."
- 화면 캡처: 근거 경로 확장 화면, 공시 문장 하이라이트

[0:45~0:52] 추가 가치
- 화면: 후속 질문 → 추가 분석 → 저장된 리서치
- 내레이션: "후속 질문으로 분석을 확장하고, 모든 리서치가 자동으로 저장됩니다."

[0:52~0:60] CTA
- 화면: 다크 배경 + 로고 + CTA 버튼
- 텍스트: "무료로 첫 분석 시작하기"
- URL: krwontology.com
- 내레이션: "공시 기반 기업 리서치. 무료로 첫 분석을 시작하세요."

---
총 길이: 60초
내레이션 톤: 차분, 전문적
배경음: 없음 또는 미묘한 일렉트로닉 (볼륨 매우 낮음)
자막: 한국어 자막 필수 (하단 중앙, 흰색 텍스트 + 검정 외곽선)

### 7.2 90초 심층 데모 (유튜브 메인 / 세일즈)

```
[0:00~0:05] 훅
- 화면: 다크 배경, 근거 경로 애니메이션

- 화면: SEC EDGAR 페이지 → KRW Ontology 전환
- 내레이션: "KRW Ontology는 SEC 공시를 온톨로지로 연결합니다. 기업의 사업 활동, 리스크, 재무 동인이 구조화된 지식 그래프로 구성됩니다."

[0:30~0:55] 답변 + 근거 경로
- 화면: 답변 생성 → 근거 경로 3개 확장
