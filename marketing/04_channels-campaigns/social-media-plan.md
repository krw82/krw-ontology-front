# KRW Ontology 소셜 미디어 계획

*작성일: 2026-05-23*

## 요약

KRW Ontology의 소셜 미디어 전략은 프리런치 인지도 구축에서 시작해 런치 후 가입 전환으로 이어지는 퍼널을 설계한다. 한국어 사용 투자자가 실제 활동하는 채널(유튜브, 네이버 블로그, 엑스, 링크드인)에 집중하며, 콘텐츠는 "공시 근거를 보여주는 AI"라는 핵심 가치를 일관되게 전달한다.

**핵심 원칙:** 근거 경로를 시각적으로 보여주는 콘텐츠가 가장 강력한 자산이다.

## 1. 채널별 우선순위 및 역할

| 우선순위 | 채널 | 역할 | 타겟 | 주 발행 빈도 |
|----------|------|------|------|-------------|
| 1 | YouTube | 제품 데모, 기업 분석 예시, 교육 콘텐츠 | 개인/프로 투자자 | 주 1~2회 |
| 2 | 네이버 블로그 | SEO 기반 상세 분석 글, use-case 설명 | 네이버 검색 유입 | 주 2~3회 |
| 3 | 엑스(Twitter/X) | 실시간 공시 분석 공유, 기업 인사이트 | 투자 커뮤니티 | 일 1~3회 |
| 4 | LinkedIn | 전문가 대상 심층 분석, 프로 기능 소개 | 프로 투자자, 애널리스트 | 주 2~3회 |
| 5 | Instagram | 시각 콘텐츠, 숏폼 데모, 스토리 | 젊은 투자자 | 주 3~4회 |

## 2. 콘텐츠 필러 전략

### 2.1 필러 구성

| 필러 | 비중 | 내용 | 주 포맷 |
|------|------|------|---------|
| 기업 분석 예시 | 30% | 특정 티커의 공시 분석 시연 (NVDA, AMZN, AAPL 등) | 유튜브 영상, 블로그 글, 엑스 스레드 |
| 근거 중심 AI 교육 | 25% | AI 리서치에서 근거 확인이 중요한 이유, 사용법 | 유튜브 숏츠, 인스타 캐러셀, 블로그 |
| 제품 업데이트 | 15% | 새 기능, 지원 회사 추가, 온톨로지 개선 | 엑스, 링크드인, 유튜브 커뮤니티 |
| 공시 리서치 워크플로우 | 20% | 10-K/10-Q 분석 방법, 질문 템플릿 | 블로그, 유튜브, 링크드인 |
| 빌드 노트/뒷이야기 | 10% | 제품 개발 과정, 온톨로지 설계 철학 | 엑스, 링크드인, 유튜브 |

### 2.2 필러별 콘텐츠 아이디어

**기업 분석 예시 (30%)**
- "NVDA 데이터센터 성장 요인을 최근 10-K 기준으로 분해해보기"
- "AMZN 클라우드 이익률 변화, 공시 원문 근거로 추적하기"
- "AAPL 서비스 매출 리스크, 어느 사업 활동과 연결되는지"
- "TSMC 리스크 팩터, 공시에서 놓치기 쉬운 문장 찾기"
- "MSFT 클라우드 세그먼트, 10-K에서 핵심 동인 추출하기"

**근거 중심 AI 교육 (25%)**
- "AI 요약 vs 근거 경로: 둘의 차이가 왜 중요한가"
- "공시 원문 근거를 확인하는 3가지 방법"
- "일반 챗봇이 공시 분석에 부족한 이유"
- "투자 리서치에서 출처 추적이 중요한 이유"
- "근거 경로가 있는 답변을 읽는 방법"

**공시 리서치 워크플로우 (20%)**
- "10-K 분석 순서: 질문 -> 답변 -> 근거 -> 다음 질문"
- "세그먼트 분석, 공시에서 어디를 봐야 할까"
- "리스크 팩터 분석, 질문 템플릿 5개"
- "실적 동인 분석, 매출/마진/비용 구조 파악하기"
- "투자 thesis를 공시로 검증하는 워크플로우"

## 3. YouTube 전략

### 3.1 채널 포지셔닝

- **채널명:** KRW Ontology (또는 "공시 근거 리서치 AI")
- **카테고리:** 금융 교육 / 투자 도구 리뷰
- **토네톤:** 차분하고 전문적. 과장 없이 제품 기능을 시연
- **언어:** 한국어 메인, 영어 자막 선택적

### 3.2 콘텐츠 유형별 발행 계획

| 유형 | 빈도 | 길이 | 목적 |
|------|------|------|------|
| 기업 분석 데모 | 주 1회 | 8~15분 | 핵심 콘텐츠, 검색 유입 |
| 숏폼 데모 | 주 2~3회 | 30~60초 | 도달 확대, 인지도 |
| 제품 튜토리얼 | 월 2회 | 5~10분 | 활성화, 온보딩 |
| 공시 분석 팁 | 월 2회 | 5~8분 | 교육, 신뢰 구축 |

### 3.3 기업 분석 데모 영상 구조 (8~15분)

```
[0:00~0:30] 훅: 이번 주 분석할 기업과 질문 소개
[0:30~1:30] 배경: 왜 이 기업/질문이 지금 중요한지
[1:30~8:00] 실제 데모: KRW Ontology에서 질문 -> 답변 -> 근거 확인
[8:00~10:00] 근거 심층 분석: 인용된 공시 문장 해설
[10:00~12:00] 추가 질문: 후속 분석으로 답변 확장
[12:00~13:00] 요약: 이번 분석에서 발견한 핵심 인사이트
[13:00~14:00] CTA: 무료 체험 안내, 다음 주 분석 예고
```

### 3.4 숏폼 영상 아이디어 (30~60초)

1. **"이 공시 문장이 의미하는 것"** — 특정 공시 문장 캡처 + 30초 해설
2. **"질문 하나로 근거까지"** — 빠른 제품 데모 (질문 -> 답변 -> 근거 클릭)
3. **"10-K에서 놓친 문장"** — 주목받지 않지만 중요한 공시 내용
4. **"AI가 찾은 근거 경로"** — 근거 경로 시각화 화면 캡처 + 설명
5. **"이렇게 질문하세요"** — 좋은 질문 vs 나쁜 질문 비교

### 3.5 검색 최적화 (YouTube SEO)

**타겟 키워드:**
- "10-K 분석", "SEC 공시 분석", "기업 공시 AI"
- "NVDA 공시 분석", "AMZN 10-K", "미국 주식 공시"
- "기업 리서치 도구", "투자 분석 AI"

**썸네일 원칙:**
- 티커 심볼 크게 표시
- "근거 경로" 또는 "공시 원문" 텍스트 포함
- 다크 배경 + 네온 악센트 (제품 브랜드 컬러)
- 제품 UI 스크린샷 포함

## 4. 네이버 블로그 전략

### 4.1 포지셔닝

- **블로그 성격:** 정보성 글 + SEO 랜딩 페이지
- **톤:** 전문적이지만 접근 가능한 설명문 스타일
- **키워드 전략:** "기업 공시 분석 AI", "10-K 분석 방법" 등 검색 의도 포착

### 4.2 발행 계획

| 유형 | 빈도 | 길이 | 목적 |
|------|------|------|------|
| 기업 분석 상세 글 | 주 1~2회 | 2,000~4,000자 | SEO, 검색 유입 |
| 사용법/튜토리얼 | 주 1회 | 1,500~3,000자 | 제품 교육 |
- 공시 용어 해설 | 월 2회 | 1,000~2,000자 | 기초 교육, 초보 유입 |

### 4.3 주요 글 주제 (초기 20개)

**기업 분석 (10편)**
1. NVDA 10-K 핵심 분석: 데이터센터 성장 동인과 리스크
2. AMZN 10-K 분석: AWS 이익률 변화의 근거
3. AAPL 10-K 분석: 서비스 매출 리스크와 사업 활동 연결
4. MSFT 10-K 분석: 클라우드 세그먼트 실적 동인
5. GOOGL 10-K 분석: 광고 매출 리스크 팩터
6. TSLA 10-K 분석: 자동차 매출 마진 동인
7. META 10-K 분석: 리얼리티 랩스 투자와 근거
8. TSMC 20-F 분석: 리스크 팩터 심층 분석
9. NFLX 10-K 분석: 콘텐츠 투자와 매출 동인
10. AVGO 10-K 분석: AI 반도체 수요와 공시 근거

**교육/튜토리얼 (6편)**
1. 10-K 분석 방법: 초보자를 위한 가이드
2. SEC 공시에서 핵심 정보를 찾는 방법
3. AI 리서치에서 근거 확인이 중요한 이유
4. 기업 분석 질문 템플릿 30선
5. 세그먼트 분석: 공시에서 세그먼트 정보 읽기
6. 리스크 팩터 분석: 투자자가 놓치는 부분

**제품 소개 (4편)**
1. KRW Ontology 소개: 근거 경로가 남는 리서치 AI
2. 질문 하나로 기업 공시 분석하는 방법
3. 근거 경로를 확인하는 3단계 워크플로우
4. 무료 체험으로 첫 분석을 시작하는 방법

### 4.4 SEO 최적화

- **제목:** 티커 + "공시 분석" + 핵심 인사이트 (예: "NVDA 10-K 분석: 데이터센터 성장 동인과 공시 근거")
- **메타 설명:** 150자 이내, 검색 의도 충족
- **내부 링크:** 관련 기업 분석 글 상호 연결
- **외부 링크:** SEC EDGAR 원문 링크 포함 (신뢰도)
- **이미지:** 제품 스크린샷, 근거 경로 캡처, 공시 문장 하이라이트

## 5. 엑스(Twitter/X) 전략

### 5.1 계정 포지셔닝

- **계정 유형:** 회사 계정 + 파운더 개인 계정 (병행 권장)
- **언어:** 한국어 메인, 영어 혼용 (글로벌 투자 커뮤니티 접근)
- **톤:** 간결하고 인사이트 중심. 링크보다 인사이트 우선

### 5.2 발행 계획

| 유형 | 빈도 | 길이 | 목적 |
|------|------|------|------|
| 공시 인사이트 | 일 1~2회 | 1~3트윗 | 일관된 가치 제공 |
| 스레드 | 주 2~3회 | 5~15트윗 | 심층 분석, 도달 확대 |
| 제품 업데이트 | 주 1회 | 1~3트윗 | 기능 소개 |
| 리트윗+코멘트 | 일 1~2회 | 코멘트 1~2문장 | 관계 구축 |

### 5.3 공시 인사이트 트윗 템플릿

**유형 A: 공시 문장 인용**
```
[티커] 최근 10-K에서 이 문장이 눈에 걸렸습니다:

"인용된 공시 문장 (영어)"

이게 의미하는 것:
→ 포인트 1
→ 포인트 2
→ 포인트 3

KRW Ontology에서 근거 경로로 확인 가능.
```

**유형 B: 비교 분석**
```
[티커]의 [지표] 변화:

이전 분기: 수치
이번 분기: 수치
변화: +/-%

공시에서 밝힌 이유:
→ 근거 1
→ 근거 2

→ 이 근거를 KRW Ontology에서 질문 하나로 추출
```

**유형 C: 질문 템플릿 공유**
```
이런 질문을 KRW Ontology에 해보세요:

"[예시 질문]"

답변에 포함되는 것:
✓ 공시 원문 인용
✓ 근거 경로
✓ 관련 사업 활동 연결

무료로 시도: krwontology.com
```

### 5.4 스레드 구조 (5~15트윗)

```
1/ 훅: "NVDA 데이터센터 성장 요인을 10-K에서 추출했습니다"

2/ 배경: 왜 이 분석이 지금 중요한지

3-4/ 공시에서 발견한 핵심 데이터 포인트

5-7/ 근거 분석: 공시 문장 인용 + 해석

8-10/ 연결된 리스크와 세그먼트 정보

11-12/ KRW Ontology에서 어떻게 이 분석을 재현하는지 (스크린샷)

13/ 요약: 핵심 인사이트 3줄

14/ CTA: "이런 분석을 직접? krwontology.com에서 무료 체험"
```

### 5.5 타겟 계정 (관계 구축)

- 한국어 투자 인플루언서 20~30계정
- 영어권 SEC/filing 분석 계정 10~20계정
- AI + finance 크리에이터 10~15계정
- 독립 애널리스트, 뉴스레터 작성자

## 7. Instagram 전략

### 7.1 포지셔닝

- **타겟:** 20~40대 한국어 사용 투자자 중 시각 콘텐츠 선호
- **톤:** 접근 가능한 전문성. 복잡한 내용을 시각적으로 단순화
- **목적:** 인지도 확대, 유튜브/블로그로 트래픽 유도

### 7.2 발행 계획

| 유형 | 빈도 | 포맷 | 목적 |
|------|------|------|------|
| 캐러셀 | 주 2회 | 5~8슬라이드 | 교육, 저장 유도 |
| 릴스 | 주 1~2회 | 15~30초 | 도달 확대 |
| 스토리 | 일 1~3개 | 설문/퀴즈/링크 | 참여, 트래픽 |

### 7.3 캐러셀 콘텐츠 아이디어

1. **"10-K에서 가장 먼저 읽어야 할 섹션 5개"** — 슬라이드당 1섹션 설명
2. **"AI가 공시를 분석하는 방법"** — 질문 -> 온톨로지 -> 근거 경로 시각화
3. **"이 공시 문장이 의미하는 것"** — 인용문 + 해석 + 관련성
4. **"투자 질문 템플릿"** — 마진/성장/리스크/세그먼트별 질문 예시
5. **"일반 AI 요약 vs 근거 경로"** — 비교 시각화

### 7.4 릴스 아이디어 (15~30초)

1. **"질문 하나로 공시 근거까지 30초"** — 제품 빠른 데모
2. **"이 공시 문장 숨은 의미"** — 문장 인용 + 빠른 해설
3. **"이렇게 질문하면 더 좋은 답변이 나옵니다"** — 질문 팁
4. **"근거 경로가 보이면 다릅니다"** — before/after 비교

## 9. 성장 전략

### 9.1 프리런치 (런치 전 4~6주)

**목표:** 채널별 초기 팔로워/구독자 확보

| 채널 | 목표 | 전략 |
|------|------|------|
| YouTube | 100~300구독자 | 기업 분석 영상 4~6편 사전 발행 |
| 네이버 블로그 | 500~1,000 일 방문자 | SEO 키워드 타겟 글 10편 이상 |
| 엑스 | 200~500팔로워 | 공시 인사이트 꾸준 발행, 관계 구축 |
| LinkedIn | 100~300팔로워 | 심층 분석 + 업계 참여 |
| Instagram | 200~500팔로워 | 캐러셀/릴스 + 해시태그 전략 |

**프리런치 액션:**
1. 유튜브 채널 개설 + 트레일러 영상 1개
2. 네이버 블로그 개설 + 초기 글 5편 동시 발행
3. 엑스 계정 개설 + 공시 분석 트윗 시작
4. LinkedIn 회사 페이지 + 파운더 개인 프로필 최적화
5. Instagram 계정 개설 + 초기 캐러셀 3개 준비

### 9.2 런치 초기 (1~3개월)

**목표:** 채널별 팔로워 2~3배 성장, 가입 전환 시작

- 런치 발표 영상/포스트 모든 채널 동시 발행
- "무료로 첫 분석 시작" CTA 일관 적용
- 유튜브 기업 분석 영상 주 1회 꾸준 발행
- 네이버 블로그 SEO 글 + 제품 소개글 병행
- 엑스에서 런치 관련 멘션에 적극 응답

### 9.3 스케일링 (4~6개월)

**목표:** 채널별 의미 있는 도달 확보, 유기적 성장 가속

- 성과 높은 콘텐츠 유형에 집중
- 콜라보레이션: 한국 투자 유튜버/인플루언서와 협업
- 유료 광고로 상위 퍼널 콘텐츠(영상, 블로그 글) 확대
- 커뮤니티 마케팅과 연계 (팍스넷, 종목토론방)

## 10. 참여 전략

### 10.1 일일 참여 루틴 (30분)

1. **댓글 응답** (5분) — 모든 채널의 최근 댓글에 답변
2. **타겟 계정 참여** (15분) — 한국 투자 커뮤니티 인플루언서 5~10계정 포스트에 의미 있는 댓글
3. **공유/리포스트** (5분) — 관련 업계 콘텐츠에 코멘트 추가 공유
4. **DM** (5분) — 신규 팔로워 또는 잠재 사용자에게 개인화된 메시지

### 10.2 관계 구축 타겟

- **유튜브:** 한국 투자 교육 채널 (구독자 1만~10만)
- **엑스:** 한국어 투자 인플루언서, SEC/filing 분석 계정
- **LinkedIn:** 자산운용사 애널리스트, 독립 리서치 펌
- **인스타그램:** 투자 팁 계정, 금융 교육 크리에이터

### 10.3 품질 댓글 원칙

- "좋은 글이에요" 수준의 댓글은 피하기
- 새로운 인사이트나 관련 경험을 추가
- 공시 근거나 구체적인 데이터 포인트 제시
- 때로는 예의 바른 반론으로 대화 유도
