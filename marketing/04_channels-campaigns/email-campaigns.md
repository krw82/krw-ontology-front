# KRW Ontology 이메일 캠페인 전략

*작성일: 2026-05-23*

## 요약

KRW Ontology의 이메일 마케팅은 가입 후 활성화(Activation)와 유료 전환(Conversion)을 핵심 목표로 한다. 라이프사이클 5통 시퀀스로 첫 분석을 유도하고, 트리거 이메일로 사용량 한계, 업그레이드, 재참여, 윈백을 관리한다.

**핵심 원칙:** 모든 이메일은 한 통에 한 가지 목적, 한 가지 CTA.

---

## 1. 이메일 인프라 설정

### 1.1 발송 도구

- **트랜잭셔널 이메일:** Resend (개발자 친화적, Supabase 연동 용이)
- **마케팅 이메일:** Customer.io 또는 Resend + 자체 시퀀스 엔진
- **발송 도메인:** email.krwoontology.com (별도 서브도메인)
- **발신자:** KRW Ontology <hello@krwontology.com>

### 1.2 인증 설정

- [ ] SPF 레코드 설정
- [ ] DKIM 서명 활성화
- [ ] DMARC 정책 설정 (p=quarantine)
- [ ] 발송 도메인 워밍 (첫 주 일 10~20통, 점진 증가)

### 1.3 Supabase 연동

모든 이메일 발송 이벤트를 `analytics_events`에 기록:

| 이벤트 | 트리거 | 속성 |
|--------|--------|------|
| `email_sent` | 이메일 발송 완료 | `email_type`, `sequence`, `step` |
| `email_opened` | 이메일 열기 | `email_type`, `sequence`, `step` |
| `email_clicked` | 링크 클릭 | `email_type`, `link_url`, `cta` |

## 2. 라이프사이클 5통 시퀀스

### 시퀀스 개요

```
시퀀스명: 가입 후 활성화 (Post-Signup Activation)
트리거: login_completed (is_new_user = true)
목표: 첫 질문 제출 + 첫 답변 완료 + 인용 열기
길이: 5통
타이밍: Day 0, 1, 3, 5, 7
종료 조건: answer_completed + citation_opened 발생 시 조기 종료
```

## 7. A/B 테스트 계획

### 7.1 테스트 우선순위

| 순위 | 테스트 | 변수 | 기간 | 성공 기준 |
|------|--------|------|------|-----------|
| 1 | Day 0 제목 | "첫 분석을 시작해보세요" vs "질문 하나면 됩니다" | 2주 | 오픈율 +10% |
| 2 | Day 0 CTA | "첫 분석 시작하기" vs "질문으로 분석 시작" | 2주 | CTR +15% |
| 3 | Day 1 내용 | 방법 설명 vs 예시 시연 | 2주 | citation_opened +20% |
| 4 | Day 7 타이밍 | Day 7 vs Day 5 | 3주 | upgrade_clicked +15% |
| 5 | 한도 이메일 CTA | "업그레이드" vs "플랜 비교 보기" | 3주 | CTR +15% |

### 7.2 테스트 원칙

- 한 번에 하나의 변수만 테스트
- 통계적 유의성 확보까지 최소 500통 발송
- 승자가 확정되면 기본 버전으로 채택
- 결과를 다음 시퀀스 개선에 반영

## 8. 발송 스케줄 및 타이밍

### 8.1 최적 발송 시간

| 이메일 타입 | 권장 발송 시간 (KST) | 근거 |
|-------------|---------------------|------|
| 라이프사이클 | 가입 시점 기준 (즉시/지정 시간) | 사용자 컨텍스트 유지 |
| 한도 관련 | 오전 10시 | 업무 시간 시작 후 |
| 재참여 | 화/수/목 오전 10시 | 평일 참여율 높음 |
| 윈백 | 화요일 오후 2시 | 주중 참여 최적 |

### 8.2 발송 제한 규칙

- 동일 사용자에게 **주 3회 이하** 마케팅 이메일 발송
- 트랜잭셔널 이메일(한도, 결제)은 제한에서 제외
- 라이프사이클 시퀀스 진행 중에는 다른 마케팅 이메일 발송 보류
- 수신 거부 처리: 즉시 반영, 24시간 이내 모든 시퀀스에서 제외
