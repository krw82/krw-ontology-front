# KRW Ontology 커뮤니티 및 제휴 전략

*작성일: 2026-05-23*

## 요약

KRW Ontology의 커뮤니티 마케팅은 한국어 사용 투자자가 이미 활동하는 채널(네이버 카페, 팍스넷, 종목토론방, 유튜브)에 진입하여 입소문을 유발하는 데 집중한다. 자체 커뮤니티 구축보다 기존 커뮤니티에서의 신뢰 축적을 우선하며, 인플루언서 파트너십과 플랫폼 제휴로 확장한다.

**핵심 원칙:** 커뮤니티에 가치를 먼저 제공하라. 제품 홍보는 가치 제공의 결과로 자연스럽게 이어져야 한다.

## 1. 타겟 커뮤니티 지도

### 1.1 한국 투자 커뮤니티 생태계

| 플랫폼 | 규모 | 특성 | 진입 난이도 | 우선순위 |
|--------|------|------|------------|----------|
| 네이버 카페 (미국주식투자 등) | 대형 (10만+ 회원) | 정보 공유, 질문/답변, 종목 분석 | 중간 | 최우선 |
| 팍스넷 (PKSX) | 대형 | 미국 주식 토론, 실시간 종목 분석 | 중간 | 최우선 |
| 종목토론방 (HTS/MTS 내) | 초대형 | 티커별 실시간 대화, 단기/중기 투자자 | 낮음 (간접) | 높음 |
| DC 인사이드 주식 갤러리 | 대형 | 자유로운 분위기, 밈/정보 혼합 | 낮음 | 중간 |
| 유튜브 투자 커뮤니티 | 대형 | 댓글/커뮤니티 탭, 영상 기반 | 중간 | 높음 |
| Reddit (r/koreainvesting 등) | 소형 | 영어+한국어, 글로벌 교포 | 낮음 | 낮음 |
| 디스코드/슬랙 투자 그룹 | 중소형 | 프라이빗, 실시간 시장 대화 | 높음 | 중간 |

### 1.2 타겟 커뮤니티 상세

**네이버 카페 (최우선)**

| 카페명 (예시) | 회원 수 | 특성 | 진입 전략 |
|---------------|---------|------|-----------|
| 미국주식투자 | 50만+ | 가장 큰 미국 주식 카페 | 공시 분석 게시글로 진입 |
| 해외주식투자 | 30만+ | 실전 투자 중심 | 분석 리포트 형태 기여 |
| 가치투자 | 20만+ | 기업 분석 중심 | 심층 분석 글로 신뢰 구축 |
| 워런 버핏 | 10만+ | 가치투자/기업 분석 | 10-K 분석 예시 공유 |
| 주식초보 | 100만+ | 초보자 교육 | 교육적 콘텐츠 (진입 장벽 낮음) |

**팍스넷 (최우선)**

- 미국 주식 포럼 활성도 높음
- 티커별 분석글, 공시 해석글 수요 많음
- 댓글 토론이 활발하여 입소문 효과 큼

**종목토론방 (간접 진입)**

- 직접 마케팅은 불가능/비효율
- 유튜브/블로그에서 분석한 내용을 공유하는 사용자가 자연스럽게 언급하도록 유도
- "KRW Ontology로 분석했다"는 언급이 자연스럽게 퍼지는 것이 목표

## 2. 커뮤니티 진입 전략

### 2.1 진입 원칙

1. **가치 먼저, 제품 나중:** 제품 언급 없이 순수 분석 콘텐츠로 시작
2. **일관된 기여:** 주 2~3회 정기적인 분석글 게시로 인지도 구축
3. **대화 참여:** 다른 사용자의 질문에 답변, 분석글에 댓글
4. **자연스러운 제품 언급:** 3~4주 후, 분석 방법으로서 자연스럽게 제품 언급
5. **스팸 금지:** 반복적인 제품 링크, 과장된 주장, 투자 권유 절대 금지

### 2.2 네이버 카페 진입 플랜

**1단계: 순수 가치 제공 (1~4주)**

주 2~3회 공시 분석 글 게시. 제품 언급 없이 순수 분석 콘텐츠.

글 포맷:
```
제목: [티커] 10-K 핵심 분석: [주요 인사이트]

본문:
1. 배경 (왜 이 기업/주제가 지금 중요한지)
2. 공시에서 발견한 핵심 데이터 (인용 포함)
3. 분석 및 해석
4. 투자자에게 시사하는 점
5. 참고: SEC EDGAR 원문 링크

주의: 본 글은 정보 제공 목적이며, 투자 권유가 아닙니다.
```

글 주제 예시:
1. "NVDA 10-K: 데이터센터 매출 성장의 공시 근거"
2. "AMZN 10-K: AWS 이익률 변화, 공시에서 읽는 요인"
3. "AAPL 10-K: 서비스 매출 리스크, 공시가 말하는 내용"
4. "MSFT 10-K: 클라우드 세그먼트 핵심 변화"
5. "GOOGL 10-K: 광고 매출 리스크 팩터 분석"

**2단계: 분석 도구로서 언급 (5~8주)**

분석글 말미에 "이 분석은 KRW Ontology를 사용하여 작성되었습니다" 추가.
과장 없이, 도구로서 사실적으로 언급.

```
참고: 본 분석은 KRW Ontology(공시 기반 기업 분석 AI)를 사용하여
공시 원문 근거를 추출하고 정리했습니다.
근거 경로를 직접 확인하고 싶으시면 krwontology.com에서 무료 체험이 가능합니다.
```

**3단계: 커뮤니티 인플루언서로 성장 (9~12주)**

- 정기적인 독자 확보
- 다른 사용자가 "KRW Ontology로 분석한 글 올려주세요" 요청
- 카페 내 인지도 확보
- 자연스러운 입소문

### 2.3 팍스넷 진입 플랜

**접근 방식:** 네이버 카페와 동일한 원칙, 더 짧은 포맷.

글 포맷 (팍스넷에 맞게 조정):
```
[티커] 공시 분석: [핵심 인사이트 1~2문장]

- 공시에서 발견한 포인트 (2~3개)
- 근거: 공시 문장 인용
- 시사점

※ 정보 제공 목적. 투자 권유 아님.
```

**특화 전략:**
- 실적 발표 시즌에 맞춘 시의성 있는 분석
- 티커별 포럼에 해당 기업 분석 게시
- 댓글에서 추가 질문에 답변

### 2.4 유튜브 커뮤니티 진입

**접근 방식:** 투자 관련 유튜브 영상 댓글에서 전문적인 코멘트.

코멘트 템플릿:
```
좋은 분석 감사합니다. 추가로, 최근 [티커] 10-K에서 [관련 주제]에 대한
공시 문장을 확인해보면 [보충 정보]가 나옵니다.
공시 원문 근거를 확인하면 더 정확한 판단에 도움이 됩니다.
```

**주의:** 제품 링크 없이 순수 정보 제공. 유튜버에게 DM으로 제품 소개 (협업 제안은 별도).

## 3. 인플루언서 파트너십

### 3.1 인플루언서 타겟 분류

| 유형 | 팔로워 규모 | 예상 비용 | 효과 | 우선순위 |
|------|-----------|----------|------|----------|
| 마이크로 (1천~1만) | 소형 | 무료~10만 원 | 신뢰도 높음 | 최우선 |
| 미드 (1만~10만) | 중형 | 30~100만 원 | 도달+신뢰 | 높음 |
| 매크로 (10만+) | 대형 | 200만 원+ | 도달 확대 | 런치 후 |

### 3.2 타겟 인플루언서 유형

**유튜브 투자 교육 채널 (마이크로/미드)**
- 구독자 1만~5만, 미국 주식 분석 콘텐츠
- 기업 분석, 공시 해석, 리서치 방법론
- 시청자가 KRW Ontology 타겟과 일치

**유튜브 경제/금융 뉴스 채널 (미드)**
- 구독자 5만~20만
- 실적 시즌 분석, 기업 분석 콘텐츠
- 제품 데모/리뷰 형태 협업 가능

**엑스/인스타 투자 인플루언서 (마이크로)**
- 팔로워 3천~1만
- 공시 분석, 기업 리서치, 투자 아이디어 공유
- 제품 사용 후기/추천 형태

**네이버 카페 파워유저 (마이크로)**
- 카페 내 영향력 높은 분석글 작성자
- 기존 카페 진입 전략과 연계
- 제품을 사용한 분석글 작성 의뢰

## 5. 자체 커뮤니티 구축 (중장기)

### 5.1 자체 커뮤니티 타이밍

**기준:** 외부 커뮤니티에서 자연스럽게 "커뮤니티가 있나요?" 질문이 10회 이상 들어오면 시작.

**예상 시점:** 런치 3~6개월 후, 활성 사용자 500명+ 확보 시.

### 5.2 플랫폼 선택

| 플랫폼 | 장점 | 단점 | 추천 |
|--------|------|------|------|
| 디스코드 | 실시간, 채널 분할, 한국어 사용자 익숙 | 노이즈, 검색 어려움 | 후보 |
