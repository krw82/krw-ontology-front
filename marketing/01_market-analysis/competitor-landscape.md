# 경쟁사 지형 분석 — KRW Ontology

*작성일: 2026-05-23*
*분석 대상: 직접/간접 경쟁사 8개 심층 프로파일링*

---

## 1. 경쟁 지형 개요

KRW Ontology가 진입하는 시장은 **"AI 기반 기업 공시 분석"**이라는 신생 카테고리입니다. 전통적인 금융 데이터 터미널(Bloomberg, FactSet)에서부터 범용 LLM(ChatGPT, Claude)까지, 다양한 형태의 대체재가 존재합니다. 하지만 **한국어 기준 + 근거 경로 중심 + 미국 공시 특화**의 교집합을 만족하는 직접 경쟁사는 현재 없습니다.

### 경쟁사 분류

| 분류 | 경쟁사 | 위협 수준 |
|------|--------|-----------|
| 직접 경쟁 | Quill AI, Fiscal.ai(구 FinChat) | 높음 |
| 준직접 경쟁 | AlphaSense, Perplexity Pro | 중간~높음 |
| 간접 경쟁(대체재) | ChatGPT/Claude, Bloomberg/FactSet | 중간 |
| 로컬 간접 경쟁 | 토스증권, 핀트(Fint), 한국 증권사 리서치 | 낮음~중간 |

## 2. 직접 경쟁사 프로파일

### 2.1 Quill AI

| 항목 | 내용 |
|------|------|
| **웹사이트** | quillai.com |
| **설립** | Y Combinator 배치 |
| **포지셔닝** | "AI-powered SEC Filing Platform" |
| **타겟** | 영어 사용 투자 분석가, 펀드 매니저, 투자은행 |
| **핵심 기능** | SEC 공시 질의응답, 자연어 기반 종목 스크리닝, 실적 발표 통화 분석, 인사이더 거래 추적 |
| **차별화** | 공시 원문 출처 인용(citation), 자연어 스크리닝 |
| **가격** | 정보 비공개 (영업팀 문의) |
| **한국어 지원** | 없음 |

**강점:**
- Y Combinator 백업, 초기 트랙션 확보
- SEC 공시 특화로 깊이 있는 분석
- 출처 인용(citation) 기능 제공 — KRW Ontology와 유사한 접근
- CB Insights, Tracxn 등에서 활발히 프로파일링됨

**약점:**
- 한국어 미지원 — 한국 투자자 진입 장벽
- 근거 경로(evidence path)가 아닌 단순 인용 수준
- 온톨로지/지식그래프 기반 구조화 없이 평문 처리
- 한국 시장에 대한 인지도 제로

**KRW Ontology 대비 위협도:** 높음. 제품 카테고리가 가장 유사. 단, 한국어 시장에서는 직접 경쟁하지 않음.

| **차별화** | 광범위한 재무 데이터 커버리지, 대시보드, 슈퍼투자자 포트폴리오 추적 |
| **가격** | Free($0), Plus(~$24-29/월), Pro(~$39-79/월) |
| **한국어 지원** | 없음 |

**강점:**
- 10만+ 상장사 커버리지로 데이터 범위가 압도적
- 자체 대시보드와 API 제공
- 무료 티어로 진입 장벽 낮음
- 실적 발표 통화, 인사이더 거래 등 풍부한 데이터 소스
- WallStreetZen 등 주요 리뷰 사이트에서 긍정적 평가

**약점:**
- 공시 원문 기반 근거 경로 미제공 — 요약 위주
- 한국어 UX 없음
- 온톨로지/지식그래프 구조 없이 평면적 데이터 제공
- 질문-답변 방식보다 데이터 조회 방식에 가까움

**KRW Ontology 대비 위협도:** 높음. 개인 투자자 대상 SaaS 모델이 동일. 단, KRW Ontology가 "근거 경로"로 차별화 가능.

## 4. 간접 경쟁사 (대체재) 프로파일

### 4.1 ChatGPT / Claude / Gemini (범용 LLM)

| 항목 | 내용 |
|------|------|
| **포지셔닝** | 범용 AI 어시스턴트 |
| **가격** | Free ~ $20/월 |
| **금융 분석 역량** | 파일 업로드 후 질의 가능, 한국어 지원 |
| **근거 인용** | 제한적 — 파일 업로드 시 부분 인용 |

**강점:**
- 이미 대다수 한국 투자자가 사용 중 — 습관 전환 비용 없음
- 한국어 완벽 지원
- 파일 업로드로 10-K/10-Q 직접 분석 가능
- 무료 또는 저렴한 가격

**약점:**
- SEC 공시 Q&A에서 약 70% 실패율 (CNBC, 2023)
- 출처 추적 불가능 — "블랙박스" 문제 (Konfuzio 연구)
- 환각(hallucination)으로 존재하지 않는 데이터 생성
- 문서 간 연결(세그먼트-리스크-실적 동인) 불가
- 동일 질문에 매번 다른 답변 — 재현성 없음
- 리서치 세션 관리와 근거 재확인 흐름이 약함

**KRW Ontology 대비 위협도:** 가장 높음. "왜 굳이 새 도구를 써야 하나?"라는 근본적 반박에 직면. 근거 경로의 검증 가능성이 핵심 차별화.

**핵심 차이 메시지:** ChatGPT/Claude/Gemini는 범용 AI 비서이고, KRW Ontology는 기업 분석에 최적화된 리서치 에이전트입니다. 사용자가 매번 공시 파일, 회사 맥락, 기간, 세그먼트, 리스크 질문을 조립하는 방식이 아니라, 지원 기업과 공시 컨텍스트에서 바로 질문하고 답변의 근거 경로를 다시 확인하는 흐름을 기본값으로 제공합니다.

| 비교 기준 | 범용 GPT | KRW Ontology |
|-----------|----------|--------------|
| 기본 목적 | 모든 주제의 대화와 생성 | 미국 상장기업 공시 분석 |
| 입력 준비 | 사용자가 파일과 맥락을 매번 준비 | 지원 기업과 공시 컨텍스트 기반 |
| 분석 구조 | 평문 문서/대화 중심 | 공시 문장, 사업 활동, 리스크, 실적 동인 연결 |
| 검증 방식 | 사용자가 별도로 출처 확인 | 답변 안에 근거 경로와 원문 확인 흐름 포함 |
| 재사용성 | 대화가 흩어지기 쉬움 | 리서치 세션과 후속 질문으로 축적 |

## 7. 차별화 포인트 요약

### KRW Ontology만의 고유한 차별화

1. **온톨로지 기반 근거 경로** — 공시 문장, 사업 활동, 리스크, 실적 동인을 연결하는 지식그래프. 단순 인용이 아닌 구조적 연결.
2. **한국어 우선 UX** — 한국 투자자의 질문 패턴과 투자 어휘에 최적화.
3. **검증 가능한 AI 리서치** — 답변에서 근거 경로를 열어 원문 공시 문장까지 추적 가능.
4. **리서치 워크플로우** — 저장된 채팅, 후속 질문, 근거 재확인으로 이어지는 반복 흐름.

### 차별화 방어 가능성 평가

| 차별화 요소 | 방어 가능성 | 이유 |
|------------|------------|------|
| 온톨로지/지식그래프 | 높음 | 구축에 상당한 엔지니어링 투자 필요 |
| 한국어 UX | 중간 | 경쟁사가 현지화로 따라잡기 가능 |
| 근거 경로 UI | 중간 | 개념은 모방 가능, 품질은 모방 어려움 |
| 리서치 워크플로우 | 낮음 | 기능적 차이, 경쟁사 추가 개발 가능 |

## 8. 위협과 기회

### 주요 위협

1. **Perplexity/ChatGPT의 금융 특화 모델 출시** — 대형 AI 기업이 공시 분석에 특화된 모델을 출시하면 경쟁 심화
2. **Quill AI의 한국어 확장** — Y Combinator 자금력으로 한국어 지원 추가 가능
3. **증권사 AI 리서치 고도화** — 한국 대형 증권사가 자체 AI 리서치 도구 출시
4. **"범용 LLM로 충분하다"는 인식** — 사용자 교육 비용 발생
5. **공시 데이터 접근성 제한** — SEC EDGAR API 정책 변경 가능성

### 주요 기회

1. **한국 개인 투자자의 미국 주식 투자 급증** — 2025년 한국인이 미국 주식 최대 외국인 매수자 (CNBC)
2. **기존 도구의 근거 검증 부재** — LLM의 70% SEC 공시 오답률이 KRW Ontology의 기회
3. **한국어 특화 틈새 시장** — 글로벌 경쟁사가 한국어 지원을 우선순위에 두지 않음
4. **AI 리서치 시장 성장** — 예측 AI 주식 시장 분야 연평균 17% 성장 전망
5. **검증 가능한 AI에 대한 수요 증가** — 환각 문제에 대한 인식 확산이 KRW Ontology에 유리
