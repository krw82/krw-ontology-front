### 시장 규모 및 행태

| 지표 | 데이터 | 출처 |
|------|--------|------|
| 한국인 미국 주식 보유액 (2025.10) | $1,700억 (역대 최대) | Medium/13F 분석 |
| 2023년 한국인 미국주식 순매수 | $250억 이상 | JournalPlus |
| 2025년 외국인 미국주식 매수 1위 국가 | 한국 | CNBC |
| 서학개미 계좌 손실 비율 (2025) | 약 50% | 한국경제 |
| 주요 정보원 | 유튜브, 종목토론방, 증권사 앱 | 매일경제 |

### 핵심 행태 패턴

1. **정보 불균형**: 기관은 공시 후 3분 내 파악, 개인은 3시간 후 인지 (비즈워치)
2. **언어 장벽**: 영어 공시 원문 해독이 근본적 장벽
3. **시차 문제**: 미국 시장 공시가 한국 시간 새벽에 발생
4. **검증 욕구**: 커뮤니티에서 "근거 없는 정보"에 대한 불만 지속
5. **AI 도구 수요 폭증**: 증권사들이 앞다투어 AI 공시 번역 서비스 출시

## 3. 페르소나 1: 적극형 개인 투자자 "서학개미 파워유저"

### 프로필

| 항목 | 내용 |
|------|------|
| **연령대** | 30-45세 |
| **직업** | 직장인, 전문직 (의사, 변호사, 엔지니어, IT 종사자) |
| **투자 경력** | 3-7년, 미국주식 경험 1-3년 |
| **포트폴리오** | 미국주식 비중 40-70%, 주로 대형주 + 일부 성장주 |
| **투자 스타일** | 직접 분석, 자신만의 thesis 구축, 주말 리서치 |
| **월 투자 리서치 시간** | 10-20시간 |
| **기술 역량** | ChatGPT 사용 경험, 엑셀 중급 이상 |

### 수행할 잡 (Jobs to Be Done)

**기능적 잡:**
- 특정 기업의 실적 변화 원인을 공시 기반으로 파악하고 싶다
- 투자 thesis가 공시 원문 근거와 일치하는지 검증하고 싶다
- 여러 기업의 리스크 팩터를 비교 분석하고 싶다

**감정적 잡:**
- "이번에도 남들보다 먼저 핵심을 파악했다"는 자신감
- "AI만 믿고 투자했다"는 불안감 없이 결정하고 싶다
- 투자 결정에 책임감을 느끼고, 근거 없는 선택을 피하고 싶다

**사회적 잡:**
- 투자 커뮤니티에서 근거 있는 의견을 제시하는 사람으로 인정받고 싶다
- "나는 뇌동매매 하지 않는다"는 이미지

### 트리거 이벤트

1. 실적 발표 시즌에 관심 종목의 예상과 다른 결과 발생
2. 특정 섹터(AI, 반도체 등)에 큰 포지션 진입 전 심층 분석 필요
3. ChatGPT로 공시 분석을 시도했다가 근거를 확인할 수 없어 불안
4. 유튜브/커뮤니티에서 "XX주 리스크가 크다"는 주장을 직접 검증하고 싶음
5. 포트폴리오 리밸런싱 전 보유 종목의 공시 재검토

### 주요 페인포인트

| 순위 | 페인포인트 | 강도 | 출처 |
|------|-----------|------|------|
| 1 | "10-K가 너무 길어서 다 읽을 시간이 없다" | 높음 | 제품 마케팅 컨텍스트 |
| 2 | "ChatGPT 답변은 빠른데 어디서 나온 말인지 확인이 안 된다" | 높음 | 공통 반응 (70% 오답률 맥락) |
| 3 | "실적 변화가 어떤 사업 활동과 연결되는지 알기 어렵다" | 높음 | 제품 마케팅 컨텍스트 |
| 4 | "한국어로 된 깊이 있는 미국 기업 분석이 부족하다" | 중간 | 커뮤니티 분석 |
| 5 | "증권사 AI 번역은 빠른데 정확성이 떨어진다" | 중간 | 비즈워치 리뷰 |

### 의사결정 기준

1. **근거 검증 가능성**: 답변의 출처를 직접 확인할 수 있는가?
2. **시간 효율성**: 수동 공시 읽기 대비 얼마나 빠른가?
3. **언어**: 한국어로 자연스럽게 질문하고 답변받을 수 있는가?
4. **가격**: 월 구독료가 투자 수익 대비 합리적인가?
5. **커버리지**: 내가 관심 있는 기업이 지원되는가?

### 고객 여정맵

```
인식 → 탐색 → 시도 → 활성화 → 반복 → 전환
  |       |       |       |        |       |
  v       v       v       v        v       v
실적    구글     첫 질문  답변    두 번째  무료 한도
발표    검색     제출     수신    질문    도달
시즌    & 비교            & 근거  제출    → 유료
도래                      경로             전환
                          확인
```

### 주요 반박/이견

| 반박 | 응답 전략 |
|------|----------|
| "ChatGPT에 물어보면 되지 않나?" | ChatGPT는 SEC 공시 질문의 70%에서 오답. 근거 추적 불가 |
| "증권사 앱에도 공시 번역이 있다" | 번역은 되지만 분석은 아님. 근거 경로와 질문 기반 리서치가 다름 |
| "무료면 써보겠는데 돈 내기는..." | 무료 티어(월 10회)로 충분히 검증 가능 |

### 핵심 어휘 (고객 언어)

- "10-K를 다 읽을 시간이 없다"
- "AI 요약은 빠른데 근거를 못 믿겠다"
- "어느 문장에서 나온 말인지 바로 확인하고 싶다"
- "투자 아이디어를 검증할 때 원문 근거가 필요하다"
- "세그먼트별로 쪼개서 봐야 하는데..."

## 4. 페르소나 2: 프로 독립 투자자 / 프리랜서 애널리스트

### 프로필

| 항목 | 내용 |
|------|------|
| **연령대** | 30-50세 |
| **직업** | 독립 애널리스트, 소형 펀드 매니저, 프라이빗 뱅커, 투자 자문 |
| **투자 경력** | 7-15년, 미국 시장 전문 경험 3-5년 |
| **포트폴리오** | 다수 기업 동시 추적, 섹터 로테이션 전략 |
| **투자 스타일** | 규칙적 리서치, 반복 가능한 워크플로우 |
| **월 투자 리서치 시간** | 40-80시간 |
| **기술 역량** | Bloomberg/FactSet 경험, 파이썬 기초, API 활용 가능 |

### 수행할 잡 (Jobs to Be Done)

**기능적 잡:**
- 다수의 기업을 동시에 모니터링하면서 개별 심층 분석도 수행하고 싶다
- 반복 가능한 리서치 워크플로우를 구축하고 싶다
- 분석 결과를 투자 의견서/브리핑으로 정리하고 싶다

**감정적 잡:**
- "나의 분석이 체계적이고 전문적이다"라는 확신
- 누락된 리스크에 대한 불안감 해소
- 클라이언트/파트너에게 신뢰감 주는 리서치 생산

**사회적 잡:**
- 전문 투자자 네트워크에서 인정받는 애널리스트
- "정보의 질이 다르다"는 평가

### 트리거 이벤트

1. 기존 Bloomberg/FactSet 구독 비용 부담으로 대안 검토
2. 담당 섹터의 실적 시즌 대량 리서크 필요
3. 새로운 기업/섹터 커버리지 시작
4. 투자 위원회/클라이언트 미팅 전 빠른 심층 분석
5. 경쟁 애널리스트보다 더 정확한 리서치 생산 압박

### 주요 페인포인트

| 순위 | 페인포인트 | 강도 |
|------|-----------|------|
| 1 | "여러 기업을 동시에 깊이 분석하기에 시간이 부족하다" | 높음 |
| 2 | "기존 터미널은 비싸고, LLM은 검증이 안 된다" | 높음 |
| 3 | "리서치 결과물을 재사용 가능하게 저장/관리하기 어렵다" | 높음 |
| 4 | "한국어로 된 전문 리서치 도구가 거의 없다" | 중간 |
| 5 | "세그먼트-리스크-실적 동인 간 연결을 수동으로 해야 한다" | 중간 |

### 의사결정 기준

1. **처리량**: 한 달에 몇 기업을 깊이 분석할 수 있는가?
2. **재현성**: 동일한 질문에 일관된 결과를 얻을 수 있는가?
3. **히스토리 관리**: 질문, Markdown 답변, 근거 확인 흐름을 다시 찾을 수 있는가?
4. **비용 효율성**: Bloomberg 대비 가격 대비 가치
5. **반복 워크플로우**: 여러 기업을 같은 질문 흐름으로 반복 점검할 수 있는가?

### 고객 여정맵

```
인식 → 탐색 → 평가 → 도입 → 고도화 → 확장
  |       |       |       |       |        |
  v       v       v       v       v        v
비용    대안     무료     Pro     워크플로우  Power
```

## 5. 페르소나 3: 금융 콘텐츠 크리에이터 / 뉴스레터 작가

### 프로필

| 항목 | 내용 |
|------|------|
| **연령대** | 25-40세 |
| **직업** | 주식 유튜버, 네이버 블로거, 텔레그램 채널 운영자, 뉴스레터 작가 |
| **팔로워** | 1,000-100,000명 구독자 |
| **콘텐츠 주제** | 미국주식 분석, 섹터 전망, 기업 심층 분석 |
| **발행 주기** | 주 2-5회 |
| **수익 모델** | 광고, 유료 구독, 후원, 제휴 |
| **기술 역량** | ChatGPT 적극 활용, 캔바/프레미어 프로 사용 |

### 수행할 잡 (Jobs to Be Done)

**기능적 잡:**
- 매주 새로운 기업 분석 콘텐츠를 근거와 함께 생산하고 싶다
- 유료 구독자에게 차별화된 심층 분석을 제공하고 싶다
- 공시 발표 직후 빠르게 분석 콘텐츠를 발행하고 싶다

**감정적 잡:**
- "내 분석이 근거 없는 뇌피셜이 아니다"라는 자신감
- 구독자의 신뢰를 잃지 않고 싶다
- 정보의 질로 타 크리에이터와 차별화하고 싶다

**사회적 잡:**
- "근거 있는 분석을 하는 크리에이터"로 브랜딩
- 유료 구독자 커뮤니티의 신뢰받는 정보원

### 트리거 이벤트

1. 주요 실적 발표 후 빠른 분석 콘텐츠 제작 압박
2. 구독자가 "출처가 어디예요?"라고 질문
3. 경쟁 크리에이터가 AI 도구를 사용하여 더 빠르고 깊이 있는 분석 발행
4. 유료 구독 전환을 위해 차별화된 콘텐츠 필요
5. AI 요약 기반 콘텐츠에 대한 독자의 피로도 증가

### 주요 페인포인트

| 순위 | 페인포인트 | 강도 |
|------|-----------|------|
| 1 | "AI 요약으로 만든 콘텐츠는 다 똑같아 보인다" | 높음 |
| 2 | "출처를 명시하지 않으면 구독자 신뢰를 잃는다" | 높음 |
| 3 | "실적 시즌에 분석할 기업이 많아 시간이 부족하다" | 높음 |
| 4 | "좋은 분석 툴을 찾기 어렵고, 있어도 영어만 지원한다" | 중간 |
| 5 | "분석 결과를 바로 콘텐츠로 활용하기 어렵다" | 중간 |

### 의사결정 기준

1. **출처 인용**: 분석 결과를 콘텐츠에 인용할 수 있는가?
2. **속도**: 실적 발표 후 얼마나 빨리 분석 결과를 얻을 수 있는가?
3. **고유성**: 다른 크리에이터와 차별화된 인사이트를 제공하는가?
4. **공유/인용**: 답변 링크와 근거 문장을 콘텐츠 제작에 활용할 수 있는가?
5. **비용**: 콘텐츠 수익 대비 도구 비용 합리적인가?

## 6. 페르소나 4: 유료 투자 커뮤니티 운영자

### 프로필

| 항목 | 내용 |
|------|------|
| **연력대** | 30-50세 |
| **직업** | 유료 투자 커뮤니티/시그널 그룹 운영자 |
| **커뮤니티 규모** | 100-5,000명 유료 멤버 |
| **월 수익** | 500만-5,000만원 (멤버십 기반) |
| **핵심 가치 제공** | 매일/매주 기업 분석, 시장 전망, 실적 리뷰 |
| **기술 역량** | 다수 AI 도구 사용 경험, 자동화 관심 |

### 수행할 잡 (Jobs to Be Done)

**기능적 잡:**
- 멤버에게 매일 새로운 기업 분석 콘텐츠를 제공하고 싶다
- 다수 기업을 빠르게 분석하여 커버리지를 넓히고 싶다
- 질문 템플릿을 만들어 반복 분석을 자동화하고 싶다

**감정적 잡:**
- "내 커뮤니티의 분석 질이 타 커뮤니티보다 높다"는 자부심
- 멤버 이탈에 대한 불안감 — 지속적 가치 제공 압박
- 분석의 정확성에 대한 책임감

**사회적 잡:**
- 업계에서 "질 높은 리서치를 제공하는 커뮤니티"로 인식
- 멤버들의 입소문으로 자연스럽게 성장

### 트리거 이벤트

1. 멤버 수 증가로 요구되는 분석량 증가, 혼자 감당 불가
2. 기존 프리랜서 애널리스트 고용 비용 부담
3. 멤버들이 "다른 커뮤니티가 더 깊이 있다"고 이탈
4. 실적 시즌 대량 분석 필요
5. 커버리지 확대 (더 많은 기업/섹터 분석 요구)

### 주요 페인포인트

| 순위 | 페인포인트 | 강도 |
|------|-----------|------|
| 1 | "매일 새로운 분석 콘텐츠를 만들어내는 압박이 크다" | 높음 |
| 2 | "애널리스트 고용은 비싸고, AI만으로는 품질 보장이 안 된다" | 높음 |
| 3 | "분석 템플릿이 없어 매번 처음부터 시작해야 한다" | 중간 |
| 4 | "여러 기업을 동시에 추적하기 어렵다" | 중간 |
| 5 | "분석 결과를 멤버십 플랫폼에 쉽게 올릴 수 없다" | 중간 |

## 8. 공통 고객 언어 (Voice of Customer)

### 반복 등장하는 표현

| 표현 | 빈도 | 페르소나 |
|------|------|----------|
| "10-K를 다 읽을 시간이 없다" | 높음 | 1, 2, 3 |
| "AI 요약은 빠른데 근거를 못 믿겠다" | 높음 | 1, 2 |
| "어느 문장에서 나온 말인지 바로 확인하고 싶다" | 높음 | 1, 2, 3 |
| "실적 변화가 어떤 사업 활동과 연결되는지 보고 싶다" | 중간 | 1, 2 |
| "투자 아이디어를 검증할 때 원문 근거가 필요하다" | 중간 | 1, 2 |
| "출처를 안 보여주면 신뢰가 안 간다" | 높음 | 3, 4 |
| "다른 사람들과 다른 인사이트를 얻고 싶다" | 중간 | 3 |
| "반복적으로 쓸 수 있는 분석 워크플로우가 필요하다" | 중간 | 2, 4 |

### 사용하지 말아야 할 표현

- "수익 보장", "종목 추천", "매수 신호" — 규제 리스크 + 신뢰 훼손
- "무조건 정확", "완전 대체" — 과약속
- "hallucination-free" — 검증되지 않은 주장

## 9. 페르소나별 메시징 전략

### 적극형 개인 투자자

```
헤드라인: "공시 원문 근거가 남는 리서치 AI"
서브카피: "질문만 하세요. 답변과 근거 경로를 함께 보여드립니다."
CTA: "무료로 첫 분석 시작"
```

### 프로 독립 투자자

```
헤드라인: "기업 리서치를 반복 가능하게"
서브카피: "근거 경로가 연결된 분석을 저장하고, 재사용하세요."
CTA: "Pro 플랜으로 여러 기업 리서치 시작"
```

### 금융 콘텐츠 크리에이터

```
헤드라인: "출처가 보이는 기업 분석으로 구독자 신뢰를 높이세요"
서브카피: "공시 원문에서 추출한 근거로 차별화된 콘텐츠를 만드세요."
CTA: "무료로 첫 분석 시작"
```

### 유료 커뮤니티 운영자

```
헤드라인: "커버리지를 늘리면서 리서치 질을 유지하세요"
서브카피: "질문 템플릿으로 여러 기업을 빠르고 일관되게 분석하세요."
CTA: "Power 플랜으로 대량 리서치 시작"
```
