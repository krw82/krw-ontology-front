# 포지셔닝 전략 — KRW Ontology

*작성일: 2026-05-23*
*기반: 경쟁사 분석, 고객 페르소나, 제품 마케팅 컨텍스트*

## 1. 포지셔닝 스테이트먼트

### 공식 포지셔닝 스테이트먼트

> 한국어를 쓰는 투자자가 미국 기업을 리서치할 때, KRW Ontology는 **기업 분석에 최적화된 공시 리서치 에이전트**입니다. 온톨로지 기반 지식그래프가 공시 문장, 사업 활동, 리스크, 실적 동인을 연결하여, 질문 하나로 검증 가능한 분석 답변과 근거 경로를 제공합니다.

### 짧은 버전 (10초 이내 전달)

> "기업 분석에 최적화된 공시 리서치 에이전트."

### 타겟 질문 (제품 카테고리 정의)

"미국 기업 공시를 한국어로 질문하면서, 답변의 근거를 직접 확인하고 싶은 투자자"를 위한 도구.

### 2.2 경쟁 프레임 설정

```
              낮은 가격 접근성                    높은 가격 접근성
                    |                                  |
  높은 근거 깊이 ──┤── Bloomberg Terminal ────────────┤── KRW Ontology ★
                    |                                  |
                    |── AlphaSense ────────────────────┤── Perplexity Pro
                    |                                  |
  낮은 근거 깊이 ──┤── Fiscal.ai ─────────────────────┤── ChatGPT
```

**KRW Ontology의 독점 영역**: 높은 근거 깊이 + 높은 가격 접근성 + 한국어 UX의 교집합.

| **워크플로우** | 일회성 질의 | 저장된 채팅, 후속 질문, 근거 재확인 |

## 3. 메시징 프레임워크

### 3.1 메시징 피라미드

```
브랜드 약속:
기업 분석에 최적화된 에이전트 — 속도와 검증을 동시에

    ├── 기업 분석 특화
    │   └── 회사·공시·기간·세그먼트·리스크 맥락을 기본값으로 처리
    ├── 근거 경로
    │   └── 답변→근거경로→공시원문 흐름
    ├── 온톨로지 연결
    │   └── 공시 문장↔사업활동↔리스크↔실적동인 연결
    └── 한국어 리서치 워크플로우
        └── 질문→Markdown 답변→채팅 히스토리→후속 질문
```

### 3.2 가치 기둥 (Value Pillars)

#### 기둥 1: 기업 분석 에이전트 — "범용 GPT가 아니라, 회사 질문에 맞춘 리서치 흐름"

| 항목 | 내용 |
|------|------|
| **고객 페인** | "ChatGPT에 물어봐도 회사, 공시, 기간, 세그먼트 맥락을 매번 다시 잡아야 한다" |
| **제공 가치** | 기업 분석에 필요한 공시 근거 탐색, 사업 맥락 연결, 답변 정리, 근거 재확인이 기본 흐름 |
| **기능적 증거** | 지원 기업 컨텍스트, 공시 기반 질문, 세그먼트·리스크·실적 동인 연결, 저장된 리서치 세션 |
| **감정적 가치** | "이 도구는 기업 분석을 하려고 만든 에이전트다"라는 명확한 신뢰 |
| **vs 경쟁사** | ChatGPT는 범용 대화, Perplexity는 웹 답변, KRW Ontology는 기업 공시 리서치 워크플로우 |

#### 기둥 2: 근거 경로 — "답변이 어디서 왔는지 확인하세요"

| 항목 | 내용 |
|------|------|
| **고객 페인** | "AI 요약은 빠른데 근거를 못 믿겠다" |
| **제공 가치** | 모든 답변에 공시 원문 문장까지 추적 가능한 근거 경로 |
| **기능적 증거** | 답변 → 근거 경로 → 공시 문장 → 원문 위치 |
| **감정적 가치** | "이 답변을 믿어도 되는지 직접 확인했다"는 안심 |
| **vs 경쟁사** | Perplexity는 URL 인용, ChatGPT는 인용 없음, 증권사는 번역만 |

#### 기둥 3: 온톨로지 연결 — "공시의 구조를 이해하는 AI"

| 항목 | 내용 |
|------|------|
| **고객 페인** | "실적 변화가 어떤 사업 활동과 연결되는지 알기 어렵다" |
| **제공 가치** | 공시 문장, 사업 활동, 리스크, 실적 동인을 연결하는 지식그래프 |
| **기능적 증거** | 세그먼트→리스크→동인 간 자동 연결, 질문 하나로 다차원 분석 |
| **감정적 가치** | "전체 그림이 한눈에 보인다"는 통찰 |
| **vs 경쟁사** | Quill AI는 평문 처리, Fiscal.ai는 평면 데이터 |

#### 기둥 4: 한국어 리서치 워크플로우 — "한국어로 질문하고, 리서치를 저장하세요"

| 항목 | 내용 |
|------|------|
| **고객 페인** | "한국어로 된 깊이 있는 미국 기업 분석이 부족하다" |
| **제공 가치** | 한국어 질문→분석→저장→재사용의 완결된 워크플로우 |
| **기능적 증거** | 한국어 질의, Markdown 답변, 세션 히스토리 |
| **감정적 가치** | "영어 공시를 직접 읽지 않아도 된다"는 편의 |
| **vs 경쟁사** | 글로벌 경쟁사는 한국어 미지원, 증권사는 질의기능 없음 |

## 4. 이그제큐티브 내러티브

### 4.1 짧은 내러티브 (홈페이지용, 50단어 이내)

> 10-K를 다 읽기 전에, 먼저 투자 질문의 근거를 확인하세요.
> KRW Ontology는 기업 공시를 질문 중심으로 읽고, 답변마다 근거 경로를 남깁니다.
> 근거를 직접 확인하고, 리서치를 저장하고, 반복하세요.

### 4.2 중간 내러티브 (어바웃/투자자용, 150단어)

> 한국의 개인 투자자는 이미 미국 주식에 $1,700억 이상을 투자하고 있습니다. 하지만 여전히 10-K의 핵심을 파악하는 데는 수시간이 걸리고, ChatGPT에 물어봐도 어디서 나온 말인지 확인할 수 없습니다.
>
> KRW Ontology는 이 문제를 근거 경로(evidence path)로 해결합니다. 공시 문장, 사업 활동, 리스크, 실적 동인을 온톨로지로 연결하여, 투자자의 질문에 구조적이고 검증 가능한 답변을 제공합니다.
>
> 답변을 읽고, 근거 경로를 열어 공시 원문을 확인하고, 리서치를 저장하여 나중에 다시 활용하세요. 빠르면서도 무책임하지 않은 리서치. 그것이 KRW Ontology가 만드는 경험입니다.

### 4.3 긴 내러티브 (IR/파트너십용)

> **시장 기회**: 한국 개인 투자자는 2025년 기준 미국 주식 최대 외국인 매수자입니다. $1,700억 이상을 보유하며, 그 규모는 매년 확대되고 있습니다. 하지만 이 투자자들이 사용할 수 있는 한국어 기반의 심층 공시 분석 도구는 사실상 없습니다.
>
> **문제**: 현재 한국 투자자의 선택지는 (1) 시간을 들여 영어 공시를 직접 읽거나, (2) ChatGPT에 물어보고 근거를 확인하지 못하거나, (3) 증권사의 표면적인 공시 번역 서비스에 의존하는 것뿐입니다. LLM은 SEC 공시 질문의 약 70%에서 오답을 내고, 증권사 AI 번역은 여전히 정확성이 떨어집니다.
>
> **해결책**: KRW Ontology는 근거 경로가 남는 AI 리서치 도구입니다. 온톨로지 기반 지식그래프가 공시 문장, 사업 활동, 리스크, 실적 동인을 구조적으로 연결합니다. 투자자는 한국어로 질문하고, 답변과 함께 근거 경로를 받으며, 원문 공시 문장까지 직접 확인할 수 있습니다.
>
> **차별화**: 글로벌 경쟁사(Quill AI, Fiscal.ai)는 한국어를 지원하지 않고, 한국 서비스(증권사 AI)는 질의기반 분석이 아닙니다. 근거 경로(evidence path)와 온톨로지 기반 구조화, 한국어 UX의 결합은 KRW Ontology만의 독점적 포지션입니다.

## 6. 반박 핸들링 (Objection Handling)

### 6.1 핵심 반박 매트릭스

| # | 반박 | 위협 수준 | 응답 |
|---|------|----------|------|
| 1 | "ChatGPT에 물어보면 되지 않나?" | 최고 | ChatGPT는 SEC 공시 질문의 70%에서 오답. 출처 추적 불가. 근거 경로가 핵심 차이 |
| 2 | "증권사 앱에도 공시 번역이 있다" | 높음 | 번역은 되지만 분석은 아님. 질문→근거경로→원문의 워크플로우가 다름 |
| 3 | "Perplexity도 출처를 보여주지 않나?" | 높음 | Perplexity는 URL 인용 수준. 공시 문장 단위 정밀 인용과 구조적 연결이 다름 |
| 4 | "AI가 틀리면 어떡하나?" | 중간 | AI가 완벽하지 않음은 인정. KRW Ontology의 가치는 AI 정확도가 아니라 근거를 확인할 수 있다는 것 |
| 5 | "지원 회사가 얼마나 되나?" | 중간 | 현재 지원 회사를 "지원 회사 보기"에서 투명하게 공개. 사용 전 확인 가능 |
| 6 | "무료면 써보겠는데..." | 낮음 | 무료 티어(월 10회)로 충분히 검증 후 결정 가능 |

### 6.2 "ChatGPT vs KRW Ontology" 비교 메시징

```
Q: "ChatGPT로도 공시 분석이 가능한데, 왜 KRW Ontology가 필요한가요?"

A: 네 가지 차이가 있습니다.

1. 목적 최적화: ChatGPT는 범용 대화형 AI입니다. KRW Ontology는
   기업 분석에 맞춰진 리서치 에이전트라서 회사, 공시, 기간,
   세그먼트, 리스크, 실적 동인 맥락을 기본값으로 다룹니다.

2. 근거 경로: ChatGPT는 답변을 생성하지만, 어느 문장에서 나온 말인지
   추적할 수 없습니다. KRW Ontology는 모든 답변에 근거 경로를 남겨
   공시 원문까지 직접 확인할 수 있습니다.

3. 구조적 연결: ChatGPT는 공시를 평문으로 처리합니다. KRW Ontology는
   공시 문장, 사업 활동, 리스크, 실적 동인을 온톨로지로 연결하여
   세그먼트→리스크→동인의 관계를 한 질문으로 파악할 수 있습니다.

4. 리서치 워크플로우: ChatGPT는 대화가 끝나면 분석이 사라집니다.
   KRW Ontology는 리서치를 저장하고, 나중에 다시 검색하여 활용할
   수 있습니다.
```

## 7. 포지셔닝 맵 (시각화)

### 7.1 2x2 포지셔닝 맵

```
  높은 검증성 (근거 추적 가능)
         │
         │    Bloomberg ──────── AlphaSense
         │    FactSet
         │
         │         ★ KRW Ontology
         │
         │    Quill AI
         │
  ───────┼──────────────────────────────────
         │                          Perplexity
         │    Fiscal.ai
         │
         │              ChatGPT ── Claude
         │    증권사 AI 번역 ── 토스
         │
  낮은 검증성 (근거 추적 불가)
```

### 7.2 포지셔닝 맵 해설

- KRW Ontology는 **높은 검증성 + 개인 투자자 접근 가능**한 우하단 독점 영역
- 경쟁사들이 높은 검증성 영역(Bloomberg, AlphaSense)에 있지만 개인 투자자 접근 불가
- 접근 가능한 경쟁사(ChatGPT, Perplexity)는 검증성이 낮음
- KRW Ontology만이 이 교집합을 차지
