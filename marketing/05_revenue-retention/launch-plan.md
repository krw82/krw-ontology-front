# KRW Ontology 런칭 계획

*최종 업데이트: 2026-05-23*

---

## 1. 런칭 전략 개요

### 1.1 3단계 런칭 모델

```
프리런치 (4-6주) → 소프트런치 (4-8주) → 풀런치 (지속)
```

| 단계 | 기간 | 목적 | 사용자 | 결제 |
|------|------|------|--------|------|
| 프리런치 | 4-6주 | 제품 검증, 초기 피드백 | 초대자 50-100명 | 무료만 |
| 소프트런치 | 4-8주 | 유료 전환 검증, 퍼널 최적화 | 오픈 가입, 500-1,000명 | Free + Pro |
| 풀런치 | 지속 | 성장, 마케팅 확대 | 제한 없음 | 전체 플랜 |

### 1.2 런칭 원칙

1. **검증 우선:** 각 단계에서 핵심 가설을 검증하고 다음 단계로
2. **작게 시작:** 완벽한 런칭보다 빠른 학습
3. **데이터 기반:** 각 단계별 측정 기준을 충족해야 다음 단계로
4. **피드백 루프:** 사용자 피드백을 제품 개선에 즉시 반영

| 첫 질문 제출률 | > 70% | 로그인→질문 비율 |
| 답변 완료율 | > 85% | 질문→답변 비율 |
| 주간 재방문 | > 25% | Day-7 재방문율 |
| 치명적 버그 | 0건 | 프로덕션 에러 로그 |
| NPS/만족도 | > 30 | 간단한 설문 |

**Go/No-Go 결정:** 7개 기준 중 5개 이상 충족 시 소프트런치 진행.

## 8. 런칭 후 체크리스트

### 8.1 런칭 당일

- [ ] 모든 핵심 플로우 정상 동작 확인
- [ ] 분석 이벤트 수신 확인
- [ ] 결제 플로우 테스트 (소프트런치 이상)
- [ ] 에러 모니터링 활성화
- [ ] 소셜 미디어 포스팅 게시
- [ ] 이메일 시퀀스 활성화
- [ ] 팀원 실시간 대기

### 8.2 런칭 후 첫 주

- [ ] 일별 핵심 지표 모니터링
- [ ] 사용자 피드백 수집 및 분류
- [ ] 치명적 버그 핫픽스
- [ ] 첫 주간 리포트 생성
- [ ] 사용자 인터뷰 3-5명 진행

### 8.3 런칭 후 첫 달

- [ ] 주간 퍼널 분석
- [ ] 코호트 리텐션 곡선 확인
- [ ] 첫 A/B 테스트 설정
- [ ] 월간 비즈니스 리포트
- [ ] 다음 단계 Go/No-Go 결정
