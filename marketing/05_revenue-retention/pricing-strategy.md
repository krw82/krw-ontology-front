## 1. 가격 정책 기본 원칙

### 1.1 가치 미터 (Value Metric)

**월간 분석(질문) 횟수**를 핵심 가치 미터로 채택.

| 기준 | 판단 |
|------|------|
| 가치 정렬 | 분석을 많이 할수록 더 많은 가치를 얻는 구조 — 정렬됨 |
| 이해 용이성 | "월 N회 분석"은 직관적 — 명확함 |
| 확장성 | 사용량 증가가 자연스럽게 업셀로 연결 — 확장 가능 |
| 게임 방지 | 분석 1회 = 에이전트 실행 1회로 명확 — 조작 어려움 |

### 1.2 가격 철학

1. **가치 기반 가격 (Value-Based Pricing):** 원가가 아닌 고객이 얻는 가치에 기반
2. **투명성:** 숨겨진 요금 없이, 사용량 한계를 명확히 공개
3. **한국 시장 적합:** 한국 SaaS 시장의 가격 민감도를 반영한 진입 장벽 최소화
4. **점진적 확장:** 사용량 증가가 자연스럽게 상위 플랜으로 연결되는 구조

### 1.3 가격 책정 기준

```
상한 = 고객의 지각 가치 (Perceived Value)
실제 가격 = 대안 비용과 지각 가치 사이
하한 = 차별화된 가치가 시작되는 지점
기저 = 서비스 제공 원가 (참고용, 가격 기준이 아님)
```

## 4. 가격 결정 논리

### 4.1 Pro 가격: ₩19,900/월

**상한 분석:**
- 고객이 "한 달에 리서치 도구에 얼마까지 쓸 수 있는가?"
- ChatGPT Plus는 $20(₩28,000) — 범용 AI 기준
- Seeking Alpha Premium은 $25(₩35,000) — 전문 투자 리서치 기준
- 한국 시장 특성상 ₩30,000이 심리적 임계점

**하한 분석:**
- Motley Fool Stock Advisor ~$8/월(₩11,200) — 최저 대안
- ₩10,000 미만은 제품 가치 저하 인식 우려
- ₩15,000 이상에서야 "전문 도구" 인식

**결정:** ₩19,900
- ₩20,000 심리적 장벽 아래 (charm pricing)
- "월 2만원 미만" 인식
- 1회당 ₩199 — 커피 한잔 가격 수준의 인지

### 4.2 Power 가격: ₩39,900/월

**상한 분석:**
- 2배 사용량의 자연스러운 가격 확장
- 한국 시장에서 개인 월 구독 ₩50,000 이상은 이탈 급증
- 프로 투자자는 월 ₩40,000까지 수용 가능

**하한 분석:**
- Pro 대비 2배 이상 가격 차이 필요 (차별화 인식)
- ₩30,000 미만은 Pro와 구분 어려움

**결정:** ₩39,900
- Pro의 정확히 2배 — 이해하기 쉬운 구조
- "월 4만원 미만" 인식
- 1회당 ₩133 — 단가 효율성 명확

### 4.3 연간 할인: 17%

**근거:**
- 2개월 무료 효과 (12개월 가격 = 10개월 × 단가)
- SaaS 업계 표준 연간 할인율 (15-20%)
- 월간 결제 부담 완화 + 장기 커밋 유도
- LTV 증가: 연간 구독자의 이탈률이 월간 대비 30-50% 낮음

## 5. Good-Better-Best 프레임워크 적용

### 5.1 앵커링 전략

```
Power  ₩39,900/월  ← 앵커 (높은 가격으로 인지 조정)
Pro    ₩19,900/월  ← 추천 (대다수가 선택할 '가장 합리적' 옵션)
Free   ₩0          ← 진입 (가치 체험용)
```

**Pro를 "추천 플랜"으로 하이라이트:**
- "대부분의 투자자가 선택하는 플랜" 뱃지
- 가격 비교 테이블에서 Pro를 중앙에 배치
- Free → Pro 전환을 주요 전환 목표로 설정

### 5.2 디코이(Decoy) 효과

- Free(10회) → Pro(100회) 간 사용량 10배 차이
- Pro(₩19,900/100회) vs Power(₩39,900/300회)
  - Pro: 회당 ₩199
  - Power: 회당 ₩133 (33% 저렴)
  - Power의 회당 단가 우위가 대량 사용자에게 자연스러운 업셀 유도

### 5.3 업셀 경로 설계

```
Free (10회) → 한계 도달 → "이번 달 무료 분석을 모두 사용했습니다"
                    ↓
              Pro (₩19,900) → 사용량 증가 → 한계 도달
                    ↓
              Power (₩39,900) → 대량 리서처
```

3. **가치 먼저, 가격 나중:** 할인 전 제품 가치를 먼저 체험하게 할 것
4. **과도한 할인 지양:** 50% 이상 할인은 브랜드 가치 훼손 우려

| PortOne (포트원) | 한국 결제수단 완비 | 글로벌 확장 시 제한 |
| 토스페이먼츠 | 한국 UX 최적화 | SaaS 구독 특화 약함 |

**권장:** 런칭 초기에는 PortOne 또는 토스페이먼츠로 한국 결제에 최적화, 글로벌 확장 시 Stripe 추가.
