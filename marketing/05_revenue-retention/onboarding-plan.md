## 1. 온보딩 설계 원칙

### 1.1 핵심 철학

**"배우게 하지 말고, 하게 하라."**

온보딩은 튜토리얼이 아닌 **첫 번째 가치 경험(Aha! Moment)**이어야 한다.

1. **실행 우선:** 긴 설명 대신 실제 분석을 먼저 실행
2. **최소 결정:** 첫 세션에서 요구하는 선택지를 최소화
3. **맥락적 안내:** 빈 화면이 아닌, 의미 있는 시작점 제공
4. **점진적 발견:** 모든 기능을 한 번에 소개하지 않고 단계적으로
5. **근거 경로가 핵심:** 첫 답변에서 반드시 인용구를 열어보게 유도

### 1.2 활성화 정의

**활성화(Activation) = 사용자가 다음 3단계를 완료한 상태:**

1. 질문을 제출하고 답변을 받음 (`question_submitted` → `answer_completed`)
2. 최소 1개의 인용구/근거 경로를 열어봄 (`citation_opened`)
3. 두 번째 질문을 하거나 7일 내 재방문

### 1.3 온보딩 목표

| 지표 | 목표 | 측정 기준 |
|------|------|-----------|
| 첫 질문 제출률 | > 80% | 로그인 후 첫 질문 / 로그인 완료 |
| 첫 답변 완료율 | > 90% | 질문 후 답변 완료 / 질문 제출 |
| 첫 인용구 열기율 | > 60% | 답변 후 인용구 열기 / 답변 완료 |
| Day-7 재방문율 | > 30% | 7일 내 재방문 / 첫 세션 사용자 |
| 활성화율 | > 50% | 활성화 완료 / 신규 가입 |

## 2. 첫 실행 경험 (First-Run Experience)

### 2.1 진입 경로별 플로우

#### 경로 A: 홈페이지 → "무료로 첫 분석 시작"

```
홈페이지 CTA 클릭
    ↓
Google 로그인 (필요시)
    ↓
로그인 완료 → 원래 이동하려던 경로로 복귀
    ↓
빈 채팅 화면에 스타터 질문 표시
```

#### 경로 B: 기업 목록 → 특정 기업 선택

```
/companies 페이지에서 기업 선택
    ↓
Google 로그인 (필요시)
    ↓
해당 기업의 채팅 화면에 기업별 스타터 질문 표시
```


## 3. 스타터 질문 설계

### 3.1 글로벌 스타터 (기업 미선택 시)

5개의 높은 품질 스타터 질문을 제시. 사용자가 1-클릭으로 실행 가능.

| 질문 | 가치 포인트 | 근거 유형 |
|------|------------|----------|
| "AAPL 서비스 매출 성장 동인을 최근 공시 기준으로 분석해줘" | 세그먼트 분석 | 10-K 비즈니스 설명 |
| "NVDA 데이터센터 매출 성장 요인을 분해해줘" | 성장 동인 분해 | MD&A, 세그먼트 |
| "AMZN 클라우드 이익률이 왜 바뀌었는지 근거와 함께 정리해줘" | 마진 분석 | 손익, MD&A |
| "TSLA 핵심 리스크 요인을 최근 10-K로 정리해줘" | 리스크 분석 | Risk Factors |
| "MSFT 세그먼트별 실적 동인을 비교해줘" | 비교 분석 | 세그먼트 보고 |

### 3.2 기업별 스타터 (특정 기업 선택 시)

기업 컨텍스트에 맞춘 질문을 자동 생성.

**AAPL 선택 시 예시:**

| 카테고리 | 스타터 질문 |
|----------|-----------|
| 매출 동인 | "AAPL 서비스 매출이 제품 매출 대비 어떻게 성장하고 있나요?" |
| 마진 분석 | "AAPL의 제품 vs 서비스 마진 구조를 비교해줘" |
| 리스크 | "AAPL이 공시에서 밝힌 주요 공급망 리스크는 무엇인가요?" |
| 세그먼트 | "AAPL의 지역별 매출 동향을 최근 공시 기준으로 보여줘" |
| 논문 검증 | "AAPL이 AI에 투자를 늘리고 있다는 thesis를 공시 근거로 검증해줘" |

**NVDA 선택 시 예시:**

| 카테고리 | 스타터 질문 |
|----------|-----------|
| 매출 동인 | "NVDA 데이터센터 매출 성장의 주요 요인은 무엇인가요?" |
| 마진 분석 | "NVDA의 gross margin 변화 요인을 분해해줘" |
| 리스크 | "NVDA가 공시에서 언급한 중국 시장 리스크를 정리해줘" |
| 세그먼트 | "NVDA의 제품별 매출 구성 변화를 보여줘" |
| 논문 검증 | "NVDA의 AI 수요가 지속 가능하다는 thesis를 공시로 검증해줘" |

### 3.3 질문 카테고리별 템플릿

| 카테고리 | 템플릿 | 사용자 입력 |
|----------|--------|------------|
| 매출 동인 | "{티커}의 매출 성장 동인을 최근 공시 기준으로 분해해줘" | 티커만 |
| 마진 분석 | "{티커}의 {항목} 마진 변화 원인을 근거와 함께 정리해줘" | 티커 + 항목 |
| 리스크 | "{티커}의 핵심 리스크 요인을 최근 10-K로 정리해줘" | 티커만 |
| 세그먼트 | "{티커}의 세그먼트별 실적 동인을 비교해줘" | 티커만 |
| 논문 검증 | "{주장}을 {티커} 공시 근거로 검증해줘" | 티커 + 주장 |

## 4. 첫 답변 후 인용구 넛지

### 4.1 인용구 열기 유도

**목표:** 첫 답변을 받은 사용자가 반드시 최소 1개의 인용구를 열어보도록 유도.

**답변 완료 직후 표시:**

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  📊 분석 완료                                    │
│                                                  │
│  AAPL의 서비스 매출 성장 동인 분석 결과:          │
│  (답변 내용...)                                   │
│                                                  │
│  ┌─── 인용구 ────────────────────────────────┐   │
│  │  [1] 10-K p.42 "Services net sales..."    │   │
│  │  [2] 10-K p.38 "App Store revenue..."     │   │
│  │  [3] 10-K p.45 "iCloud growth..."         │   │
│  └────────────────────────────────────────────┘   │
│                                                  │
│  👆 인용구를 클릭하면 공시 원문 근거를 확인할     │
│     수 있습니다. 한 번 클릭해보세요!               │
│                                                  │
└──────────────────────────────────────────────────┘
```

### 4.2 첫 인용구 열기 후

**첫 인용구를 열면 간단한 안내 표시:**

```
✓ 근거 경로를 확인했습니다!

이 답변은 10-K 42페이지의 해당 문장에서 나왔습니다.
다른 인용구도 클릭해서 근거를 비교해보세요.
```

### 4.3 인용구를 열지 않은 경우

**조건:** 답변 완료 후 30초 이내 인용구 미클릭

```
💡 이 답변의 근거가 궁금하시면
   아래 인용구를 클릭해보세요. 공시 원문을 바로 확인할 수 있습니다.
```

## 5. 세션별 온보딩 진행

### 5.1 첫 세션 (Session 1)

| 단계 | 행동 | 안내 |
|------|------|------|
| 진입 | 로그인 완료 | 스타터 질문 표시 |
| 질문 | 스타터 클릭 또는 직접 입력 | 질문 없음 (자유 입력) |
| 답변 | 분석 완료 | 인용구 넛지 |
| 근거 | 인용구 열기 | "근거를 확인했습니다!" |
| 후속 | 2번째 질문 유도 | "다른 질문도 해보세요" |

### 5.2 두 번째 세션 (Session 2)

| 단계 | 행동 | 안내 |
|------|------|------|
| 진입 | 재방문 | "다시 오셨네요! 새로운 질문을 시작하세요" |
| 질문 | 새로운 질문 | 다른 카테고리의 스타터 제안 |
| 답변 | 분석 완료 | 기능 힌트: "결과를 비교해보세요" |

### 5.3 세 번째 세션 이후

- 스타터 질문 대신 최근 리서치 히스토리 표시
- "이전에 조사한 기업에 이어서 질문해보세요" 유도
- 새 기능 소개 (Pro 기능 미리보기 등)

## 8. 점진적 기능 발견 (Progressive Disclosure)

### 8.1 기능 노출 타임라인

| 시점 | 노출 기능 | 안내 방식 |
|------|----------|----------|
| 첫 질문 | 스타터 질문, 채팅 입력 | 빈 상태 자동 표시 |
| 첫 답변 | 인용구 열기 | 답변 하단 넛지 |
| 2번째 질문 | 다른 카테고리 제안 | 스타터 갱신 |
| 3번째 답변 | 기업 전환 | 사이드바 힌트 |
| 5번째 답변 | Pro 기능 미리보기 | 소프트 게이트 |
| 8번째 답변 | 사용량 주의 | 80% 넛지 |
| 10번째 답변 | Pro 제안 | 페이월 모달 |

### 8.2 기능 안내 메시지

**기업 전환 안내 (3번째 질문 후):**
```
💡 다른 기업도 분석해보세요.
   왼쪽 사이드바에서 새 기업을 선택하거나
   질문에 티커를 포함하면 자동으로 전환됩니다.
```

**후속 질문 안내 (첫 답변 후):**
```
💡 이 답변에 대해 더 깊이 파고들 수 있습니다:
   "그 리스크가 실적에 미친 영향은?"
   "다른 세그먼트에서도 비슷한 패턴이 있나요?"
```

## 9. 개인화 전략

### 9.1 행동 기반 개인화

| 행동 신호 | 개인화 |
|----------|--------|
| 특정 기업 반복 분석 | 해당 기업 관련 스타터 우선 표시 |
| 특정 카테고리 선호 | 선호 카테고리의 질문 템플릿 우선 |
| 인용구 자주 확인 | 근거 중심 질문 제안 |
| 짧은 질문 선호 | 간결한 스타터 제안 |
| 긴 질문 선호 | 심층 분석 템플릿 제안 |

### 9.2 세션 기반 적응

- **활성 사용자 (주 3회+):** 고급 기능 팁, Pro 기능 미리보기
- **보통 사용자 (주 1-2회):** 새 카테고리 소개, 다른 기업 제안
- **비활성 사용자 (2주+ 미접속):** 리인게이지먼트 이메일, "새 공시 업데이트" 알림

## 10. 온보딩 측정 지표

### 10.1 퍼널 지표

| 단계 | 이벤트 | 목표율 |
|------|--------|--------|
| 가입 | `login_completed` | 100% |
| 첫 질문 | `question_submitted` (첫 번째) | > 80% |
| 첫 답변 | `answer_completed` (첫 번째) | > 90% |
| 첫 인용구 | `citation_opened` (첫 번째) | > 60% |
| 두 번째 질문 | `question_submitted` (두 번째) | > 40% |
| Day-7 재방문 | 세션 재시작 | > 30% |

### 10.2 시간 지표

| 지표 | 정의 | 목표 |
|------|------|------|
| 가입→첫 질문 | 로그인 완료부터 첫 질문 제출까지 | < 60초 |
| 질문→답변 | 질문 제출부터 답변 완료까지 | < 30초 |
| 답변→인용구 | 답변 완료부터 첫 인용구 열기까지 | < 30초 |
| 첫 세션 시간 | 로그인부터 세션 종료까지 | > 3분 |

### 10.3 분석 이벤트

| 이벤트 | 발생 조건 | 속성 |
|--------|----------|------|
| `starter_question_clicked` | 스타터 질문 클릭 | `question_id`, `ticker`, `category` |
| `citation_nudge_shown` | 인용구 넛지 표시 | `message_id`, `delay_ms` |
| `onboarding_step_completed` | 온보딩 단계 완료 | `step`, `time_from_login` |

## 11. 개선 실험 계획

### 11.1 우선 실험

| 실험 | 변형 A | 변형 B | 측정 |
|------|--------|--------|------|
| 스타터 질문 수 | 3개 | 5개 | 첫 질문 제출률 |
| 스타터 질문 유형 | 제네릭 | 기업별 맞춤 | 답변 완료율 |
| 인용구 넛지 | 있음 | 없음 | 인용구 열기율 |
| 환영 메시지 | 있음 | 없음 (바로 스타터) | 가입→질문 시간 |

### 11.2 후속 실험

| 실험 | 변형 | 측정 |
|------|------|------|
| 이메일 시퀀스 | 5일 vs 7일 | Day-7 재방문율 |
| 스타터 카테고리 | 전체 노출 vs 1개씩 | 카테고리 다양성 |
| 인용구 넛지 타이밍 | 즉시 vs 10초 후 | 인용구 열기율 |
