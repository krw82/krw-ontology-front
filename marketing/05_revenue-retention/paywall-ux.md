# KRW Ontology 페이월 UX 전략

*최종 업데이트: 2026-05-23*

---

## 1. 페이월 설계 원칙

### 1.1 핵심 철학

페이월은 차단이 아닌 **가치 확장의 제안**이어야 한다.

1. **가치 먼저 보여주기:** 사용자가 이미 받은 가치를 확인한 후 업셀 제안
2. **투명한 한계:** "남은 횟수"를 항상 보여주어 갑작스러운 차단 방지
3. **보존 우선:** 한계 도달 후에도 기존 리서치 히스토리 접근 유지
4. **비난하지 않기:** 유도 메시지는 가치 제안 중심, 죄책감 유발 금지
5. **맥락에 맞는 제안:** 업셀 메시지는 사용자의 현재 행동과 관련 있어야 함

### 1.2 페이월 vs 게이트 구분

| 유형 | 정의 | 적용 |
|------|------|------|
| 소프트 게이트 | 기능 미리보기, 접근은 가능하나 실행 불가 | 긴 히스토리, 고급 질문 템플릿, 우선 분석 큐 |
| 하드 페이월 | 월간 분석 한계 도달 시 추가 분석 불가 | 분석 횟수 초과 |
| 넛지 (Nudge) | 행동 유도 메시지, 서비스 이용은 가능 | 업셀 제안, 기능 안내 |

## 2. 사용량 표시 시스템

### 2.1 남은 횟수 표시

**표시 위치:**
- 채팅 입력창 하단 (항상 표시)
- 사이드바 상단 프로필 영역
- 설정 페이지

**표시 형태:**

```
기본 상태:
┌─────────────────────────────────────┐
│  이번 달 무료 분석: 7/10회 남음     │
│  ████████░░  70%                    │
└─────────────────────────────────────┘

80% 도달 시 (주의):
┌─────────────────────────────────────┐
│  ⚠ 이번 달 무료 분석: 2/10회 남음   │
│  ██░░░░░░░░  20%                    │
└─────────────────────────────────────┘

한계 도달 시:
┌─────────────────────────────────────┐
│  이번 달 무료 분석을 모두 사용했습니다 │
│  ░░░░░░░░░░  0%                     │
└─────────────────────────────────────┘
```

**Pro/Power 사용자:**
```
┌─────────────────────────────────────┐
│  Pro 플랜: 이번 달 45/100회 사용     │
│  █████░░░░░  45%                    │
└─────────────────────────────────────┘
```

### 2.2 표시 규칙

| 조건 | 동작 |
|------|------|
| 남은 횟수 > 50% | 작은 텍스트로 조용히 표시 |
| 남은 횟수 20-50% | 약간 강조, 색상 변경 |
| 남은 횟수 < 20% | 주의 아이콘, 넛지 메시지 |
| 한계 도달 | 페이월 모달 표시 |
| Pro/Power 80% 도달 | 사용량 알림 (이메일/인앱) |
| Pro/Power 한계 도달 | Power 업셀 또는 다음 달 대기 안내 |

## 3. 한계 도달 시 UX

### 3.1 Free 한계 도달 (10회)

**시나리오:** 사용자가 10번째 분석을 완료한 후 11번째 질문을 시도

**UX 흐름:**

```
1. 채팅 입력창에 질문 입력 후 전송
   ↓
2. 페이월 모달 표시 (입력창 위에 오버레이)
   ↓
3. 사용자가 이미 받은 가치 요약
   ↓
4. Pro 플랜 제안
   ↓
5a. "Pro 시작하기" → 결제 플로우
5b. "다음 달에 다시" → 모달 닫기, 기존 히스토리 유지
```

**모달 내용:**

```
┌──────────────────────────────────────────────┐
│                                              │
│  이번 달 무료 분석 10회를 모두 사용했습니다    │
│                                              │
│  ┌──────────────────────────────────────┐    │
│  │  이번 달 받은 근거 경로               │    │
│  │  • 분석 완료: 10회                    │    │
│  │  • 인용구 확인: 23회                  │    │
│  │  • 조사한 기업: 4개                   │    │
│  └──────────────────────────────────────┘    │
│                                              │
│  Pro로 월 100회 분석하세요                    │
│  ₩19,900/월 (VAT 포함)                      │
│                                              │
│  [Pro 시작하기]  [다음 달에 다시]             │
│                                              │
│  기존 리서치 결과는 언제든 확인할 수 있습니다   │
│                                              │
└──────────────────────────────────────────────┘
```

**시나리오:** Free 사용자가 7일 이전 채팅을 다시 열려고 함

```

고급 질문 템플릿은 Pro에서 제공됩니다
```

## 5. 업셀 메시징 전략

### 5.1 메시징 원칙

| 원칙 | 설명 |
|------|------|
| 가치 먼저 | 이미 받은 가치를 요약한 후 제안 |
| 구체적 숫자 | "10배 더 많은 분석" 같은 구체적 비교 |
| 맥락 연결 | 현재 행동과 관련된 기능으로 업셀 |
| 압박 없음 | "지금 당장"이 아닌 "준비되셨을 때" |
| 하위 호환 | 업셀 후에도 기존 경험이 유지됨을 강조 |

### 5.2 상황별 메시지

#### 분석 완료 직후 (가치 피크)

```
이번 달 {N}회 분석 완료!
지금까지 {M}개 근거 경로를 확인했습니다.
Pro에서는 월 100회까지 분석할 수 있습니다.
```

#### 연속 사용자 (하루 3회 이상)

```
오늘만 이미 {N}회 분석했네요!
활동적인 리서치에는 Pro가 적합합니다.
월 100회 + 90일 히스토리 + 고급 질문 템플릿
```

#### 근거 경로를 자주 확인하는 사용자

```
근거 경로를 꼼꼼히 확인하고 계시네요!
Pro에서는 더 긴 히스토리로 이전 질문과
근거 확인 흐름을 다시 열 수 있습니다.
```

#### 특정 기업 반복 분석

```
{회사명}을(를) {N}번 분석했습니다.
Pro에서는 여러 기업을 같은 질문 템플릿으로
반복 점검하고 채팅 흐름을 오래 보관할 수 있습니다.
```

### 5.3 업셀 CTA 카피

|-----|----------|
| "Pro 시작하기" | 페이월 모달 주 버튼 |
| "Pro 알아보기" | 넛지 배너, 사이드바 |

## 6. 페이월 터치포인트 맵

### 6.1 사용자 여정별 페이월

```
홈페이지 → 로그인 → 기업 선택 → 첫 질문 → 답변 완료
                                           ↓
                                     근거 확인 (1st aha!)
                                           ↓
                                     2-9번째 질문 (가치 축적)
                                           ↓
                                     8번째 완료 → 80% 넛지
                                           ↓
                                     10번째 완료 → 한계 도달
                                           ↓
                                     페이월 모달
                                           ↓
                                  ┌────────┴────────┐
                                  ↓                 ↓
                              Pro 전환          다음 달 대기
                                  ↓
                              100회 분석 시작
                                  ↓
                              80번째 → 사용량 알림
                                  ↓
                              100번째 → Power 업셀
```

### 6.2 터치포인트별 세부 UX

| 단계 | 터치포인트 | 표시 내용 | 행동 유도 |
|------|-----------|-----------|----------|
| 홈페이지 | CTA 영역 | "무료로 첫 분석 시작" | 가입 유도 |
| 첫 분석 완료 | 답변 카드 하단 | "근거 경로를 확인해보세요" | 인용구 열기 |
| 3번째 분석 | 사이드바 배너 | "Pro에서는 100회까지" | 인지만 |
| 8번째 분석 | 답변 카드 하단 | "이번 달 2회 남음" + Pro 링크 | 업셀 넛지 |
| 10번째 시도 | 페이월 모달 | 가치 요약 + Pro 제안 | 업셀 강력 유도 |
| Pro 가입 후 | 환영 메시지 | "Pro에 오신 것을 환영합니다" | 기능 안내 |
| Pro 80회 | 인앱 알림 | "이번 달 20회 남음" | 사용량 인지 |
| Pro 100회 | 페이월 모달 | Power 업셀 | Power 전환 |

## 7. 페이월 UI 컴포넌트

### 7.1 사용량 프로그레스 바

```tsx
// 개념적 컴포넌트 구조
interface UsageBarProps {
  used: number;
  total: number;
  plan: 'free' | 'pro' | 'power';
  variant: 'minimal' | 'detailed' | 'warning';
}
```

**표시 규칙:**
- `minimal`: 프로그레스 바만 (남은 횟수 > 50%)
- `detailed`: 바 + 텍스트 (남은 횟수 20-50%)
- `warning`: 바 + 텍스트 + 넛지 (남은 횟수 < 20%)

### 7.2 페이월 모달

```tsx
interface PaywallModalProps {
  trigger: 'limit_reached' | 'feature_gated' | 'usage_nudge';
  currentPlan: Plan;
  suggestedPlan: Plan;
  usageSummary: {
    analysesCompleted: number;
    citationsOpened: number;
    companiesResearched: number;
  };
}
```

### 7.3 소프트 게이트 툴팁

- 기능 버튼에 잠금 아이콘 표시
- 클릭 시 작은 툴팁으로 "Pro에서 사용 가능" 안내
- 툴팁에 Pro CTA 링크 포함

## 8. 가치 제안 강화 전략

### 8.1 "이미 받은 가치" 표시

페이월이 표시되는 순간에 사용자가 이미 경험한 가치를 정량화하여 보여줌.

**표시 항목:**

| 항목 | Free | Pro |
|------|------|-----|
| 이번 달 분석 완료 | "10회" | "100회" |
| 확인한 근거 경로 | "23개" | "245개" |
| 조사한 기업 | "4개" | "15개" |
| 절약한 추정 시간 | "약 25시간" | "약 250시간" |

**시간 절약 추정 로직:**
- 1회 수동 10-K 분석: 평균 2-3시간
- KRW Ontology 1회 분석: 평균 2-3분
- 절약 시간 = 분석 횟수 × (150분 - 3분) ≈ 분석 횟수 × 2.5시간

### 8.2 "Pro에서 추가로 얻는 것" 프레이밍

```
지금까지 무료로:
• 10회 근거 있는 분석 완료

Pro로 전환하면:
• 월 100회까지 분석 (10배 확장)
• 90일 히스토리 보관
• 고급 질문 템플릿
• 여러 기업을 같은 질문으로 반복 점검
• 이전 Markdown 답변과 근거 확인 흐름 재방문

₩19,900/월로 위 기능을 모두 사용하세요
```

### 8.3 1회당 단가 시각화

```
Pro 월 ₩19,900 / 100회 = 회당 ₩199

비교:
• 전문 리서치 보고서 1편: ₩50,000~200,000
• ChatGPT Plus 월 구독: ₩28,000 (근거 없음)
• 커피 한 잔: ₩5,000
• KRW Ontology Pro 1회 분석: ₩199
```
