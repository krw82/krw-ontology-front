## 3. 포지셔닝 & 메시징

### 3.1 포지셔닝 스테이트먼트

> "기업 분석에 최적화된 공시 리서치 에이전트"

### 3.2 메시징 계층

```
브랜드 약속: 기업 분석에 최적화된 리서치 — 속도와 검증을 동시에
    │
    ├── 기업 분석 에이전트: 회사·공시·기간·리스크 맥락을 기본값으로 처리
    ├── 근거 경로: 모든 답변에 공시 문장 출처
    ├── 온톨로지: 공시 문장↔사업활동↔리스크↔실적동인 연결
    └── 한국어 워크플로우: 질문→답변→저장→재사용
```

### 3.3 기존 GPT와의 차이

| 기존 GPT | KRW Ontology |
|----------|--------------|
| 범용 대화형 AI | 기업 분석에 최적화된 리서치 에이전트 |
| 사용자가 공시 파일, 기간, 회사 맥락을 준비 | 지원 기업과 공시 컨텍스트에서 바로 질문 |
| 답변 출처 확인을 별도로 수행 | 답변마다 공시 근거 경로 제공 |
| 일회성 대화 중심 | 저장된 리서치, 후속 질문, 근거 재확인 중심 |

### 3.4 금지 표현 / 권장 표현

| 금지 | 권장 |
|------|------|
| 수익 보장, 종목 추천 | 근거 경로, 출처 확인 |
| 완벽한 정확도 | 검증 가능한 분석 |
| AI가 대신 분석 | AI가 근거를 찾아 정리 |
| 무조건 믿을 수 있는 | 직접 확인할 수 있는 |
| GPT보다 무조건 우수 | 기업 분석에 맞춰진 에이전트 |

## 6. 전환 최적화 (CRO)

### 6.1 최우선 개선사항

1. **홈페이지 CTA 버튼 추가** — 현재 명시적 CTA 부재. "무료로 첫 분석 시작" 버튼 추가만으로 전환율 2-3배 개선 예상
2. **소셜 프루프 추가** — 사용자 수, 분석 완료 건수, 지원 기업 수 표시
3. **히어로 카피 개선** — "기업 분석에 최적화된 공시 리서치 에이전트" 또는 "10-K를 다 읽기 전에, 먼저 투자 질문의 근거를 확인하세요"

### 6.2 리드 마그넷

| 리드 마그넷 | 형식 | 게이팅 | 우선순위 |
|------------|------|--------|---------|
| 기업 공시 질문 템플릿 30개 | PDF/Markdown | Ungated + 이메일 선택 | 1순위 |
| 10-K 근거 검증 체크리스트 | PDF | Ungated | 2순위 |
| AI 답변 검증 가이드 | 블로그 포스트 | Ungated | 3순위 |
| 실적 동인 분석 워크시트 | 스프레드시트 | 이메일 필수 | 4순위 |
| 주간 공시 인사이트 뉴스레터 | 이메일 | 구독 | 5순위 |

### 6.3 A/B 테스트 우선순위

| 순위 | 테스트 | 가설 | 필요 트래픽 |
|------|--------|------|-----------|

## 9. 온보딩 & 리텐션

### 9.1 활성화 정의

사용자가 다음 3단계를 완료하면 활성화:
1. 첫 질문 제출
2. 답변 수신 완료
3. 최소 1개 인용구/근거 경로 열기

### 9.2 온보딩 플로우

```
로그인 → 스타터 질문 제안 (글로벌 5개 / 기업별 5개)
    → 질문 선택 또는 직접 입력
        → 답변 수신
            → 인용구 넛지 ("근거 경로를 확인해보세요")
                → 활성화 완료
```

### 9.3 이탈 방지

| 신호 | 대응 |
|------|------|
| 질문 빈도 감소 | "새로운 분석 아이디어" 이메일 |
| 인용구 열기율 하락 | 인용구 가치 교육 이메일 |
| 한계 도달 후 미전환 | 가치 요약 + 맞춤 제안 |
| 해지 요청 | 사유별 세이브 오퍼 |
| 결제 실패 | D+0~D+14 자동 복구 시퀀스 |

| 도메인 | 포지셔닝 적용 | 상태 |
|--------|-------------|------|
| SEO | "공시 원문 근거가 남는 기업 리서치 AI" 타이틀 일관 적용 | ✅ |
| 광고 | "근거 경로" 차별화 메시지 일관 사용 | ✅ |
