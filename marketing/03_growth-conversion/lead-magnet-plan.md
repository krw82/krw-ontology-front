## 1. 리드 마그넷 전략 개요

### 1.1 목표

- 이메일 리스트 구축 (런치 후 3개월 내 500명)
- 무료 체험→활성화 유도 (리드 마그넷 → 첫 분석 완료율 30%)
- SEO 트래픽을 이메일 구독으로 전환
- 유료 전환 경로의 시작점 역할

### 1.2 타겟 페르소나별 리드 마그넷 매핑

| 페르소나 | 주요 관심 | 최적 리드 마그넷 |
|---------|----------|----------------|
| 개인 투자자 | 빠른 기업 이해, 근거 확인 | 10-K 검증 체크리스트 |
| 프로 투자자 | 반복 리서치, thesis 검증 | 공시 질문 템플릿 30개 |
| 뉴스레터/크리에이터 | 출처 있는 콘텐츠 | AI 답변 공시 원문 검증 가이드 |
| 커뮤니티 운영자 | 멤버 대면 리서치 확장 | 실적 동인 분석 워크시트 |

### 1.3 원칙

- **단독 가치:** 이메일 없이도 페이지 자체로 유용해야 함 (ungated core)
- **제품 연결:** 모든 리드 마그넷은 "직접 해보기" CTA로 제품으로 연결
- **게이팅 전략:** PDF/다운로드는 이메일 교환, 웹 버전은 무료 공개
- **한국어 우선:** 모든 산출물은 한국어, 영문 티커와 재무 용어만 영어 병기

## 2. 리드 마그넷 #1: 10-K 근거 검증 체크리스트

### 2.1 개요

| 항목 | 내용 |
|------|------|
| 제목 | 10-K 근거 검증 체크리스트 — 공시에서 놓치는 핵심 확인 |
| 타겟 | 개인 투자자, 초중급 |
| 형식 | 웹 페이지 (ungated) + PDF 다운로드 (이메일 게이트) |
| 분량 | 체크리스트 15항목, 해설 포함 2-3페이지 |
| URL | /resources/filing-verification-checklist |

### 2.2 콘텐츠 구성

**체크리스트 항목 (15개):**

```
기본 확인 (5항목):
☐ 최근 10-K/10-Q 제출일 확인
☐ 핵심 재무 지표 전년 대비 변동 방향
☐ 매출 원인 분해 (segment별, geography별)
☐ 영업이익률 변화 방향과 원인
☐ 주요一次性 항목 식별

리스크 검증 (5항목):
☐ Risk Factors 섹션 신규/변경 항목
☐ 리스크와 실적 변동의 연결 여부
☐ 산업별/규제별 리스크 트렌드
☐ 경쟁사 대비 리스크 차이점
☐ MD&A에서 언급된 미래 리스크

근거 경로 확인 (5항목):
☐ 답변의 출처가 어느 섹션에서 왔는지 확인
☐ 세그먼트 보고서와 합산 수치의 일치
☐ 비교 기간(전년/전분기) 명확성
☐ 경영진 발언(earnings call)과 공시의 일치
☐ 숨겨진 가정이나 추정치 식별
```

### 2.3 게이팅 전략

- **웹 버전:** 전체 체크리스트 공개 (SEO + 가치 제공)
- **PDF 다운로드:** 이메일 입력 시 체크리스트 + 빈 양식 제공
- **이메일 시퀀스:** 다운로드 후 Day 1: "이 체크리스트를 AI로 자동화하는 법" → 제품 CTA

### 2.4 제품 연결

- 체크리스트 하단: "이 체크리스트를 KRW Ontology에서 자동으로 실행하기"
- CTA: "무료로 첫 10-K 분석 시작" → `/login?next=/chat`
- 예시 질문 연결: "AAPL 최근 10-K에서 매출 변화 원인을 근거와 함께 보여줘"

### 2.5 성과 지표

|------|-------------|
| 페이지 방문 | 1,000 |

| 다운로드→가입 | 60 (30% 전환율) |

## 4. 리드 마그넷 #3: AI 답변을 공시 원문으로 검증하는 방법

### 4.1 개요

| 항목 | 내용 |
|------|------|
| 제목 | AI 답변을 공시 원문으로 검증하는 방법 |
| 타겟 | 뉴스레터/크리에이터, 개인 투자자 |
| 형식 | 교육 가이드 (웹 페이지, ungated) |
| 분량 | 5단계 가이드, 1,500-2,000자 |
| URL | /resources/verify-ai-with-filings |

### 4.2 콘텐츠 구성

```
1단계: AI가 답변의 출처를 공개하는지 확인
   - 출처가 없으면 신뢰할 수 없다
   - KRW Ontology는 모든 답변에 근거 경로를 제공

2단계: 근거가 원문 문장과 일치하는지 확인
   - 의역이 아닌 원문 인용인지
   - 문맥이 잘린 인용인지 확인

3단계: 근거가 최신 공시 기반인지 확인
   - 10-K/10-Q 제출일 확인
   - 구 공시 기반 답변인지 식별

4단계: 누락된 근거가 없는지 확인
   - AI가 일부만 발췌하지 않았는지
   - 반대되는 근거도 포함되었는지

5단계: 여러 AI 도구의 답변을 교차 검증
   - 일반 챗봇 vs 전문 리서치 AI 비교
   - 공시 원문을 직접 확인하는 습관
```

### 4.3 게이팅 전략

- 전체 공개 (SEO 최우선)
- 하단에 "직접 체험해보기" CTA
- 이메일 게이트 없음 — 교육 콘텐츠로 신뢰 구축 후 제품으로 유도

### 4.4 제품 연결

- 각 단계 후 "KRW Ontology에서 이 검증 자동으로 하기" CTA
- 실제 AMZN 예시로 5단계 시연
- 최종 CTA: "지금 무료로 근거 경로 체험하기"

### 4.5 성과 지표

| 지표 | 타겟 (3개월) |
|------|-------------|
| 페이지 방문 | 1,500 |
| CTA 클릭 | 300 (20% CTR) |
| CTA→가입 | 150 (50% 전환율) |
