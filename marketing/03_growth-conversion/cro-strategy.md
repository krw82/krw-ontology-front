# CRO 전략: 전환율 최적화 마스터플랜

*최종 수정: 2026-05-23*

---

## 1. 현재 상태 진단

### 1.1 퍼널 개요

```
홈페이지 방문 → CTA 클릭 → 로그인 완료 → 첫 질문 제출 → 답변 완료 → 인용 열기 → 업그레이드
```

현재 Supabase analytics_events가 구현 전이므로, 모든 전환율은 베이스라인 측정 이후 개선을 전제로 한다.

### 1.2 기존 홈페이지 분석

**강점:**
- 히어로 헤드라인 "근거가 보이는 기업 분석 AI"가 명확하고 차별화된 가치를 전달
- 아이브로 "회사 보고서에서 찾은 답의 단서"가 제품 카테고리를 설명
- 데모 애니메이션(HomeQuestionForm)이 제품 경험을 미리 보여줌
- 증거 카드(근거/흐름/정리)가 증거 경로 컨셉을 시각화

**개선 필요:**
- 명시적 CTA 버튼이 없음: 질문 폼은 데모일 뿐, 실제 가입/시작 유도 버튼 없음
- 소셜 프루프 전무: 고객 로고, 증언, 사용자 수, 리뷰 없음
- 가격 정보 부재: 무료 10회 분석 안내가 홈페이지에 없음
- 오브젝션 핸들링 없음: "투자 조언이 아닙니다" 면책 부족
- 모바일 헤더에 로그인 버튼 숨김 처리 (hidden sm:inline-flex)
- 보조 CTA "회사 목록"이 "지원 회사 보기"보다 덜 명확

## 2. 정량적 목표

### 2.1 단계별 전환율 타겟 (런치 후 3개월 기준)

| 퍼널 단계 | 업계 벤치마크 | 1차 타겟 | 이상 타겟 |
|-----------|-------------|---------|----------|
| 홈페이지 → CTA 클릭 | 3-8% | 5% | 10% |
| CTA 클릭 → 로그인 완료 | 40-60% | 50% | 65% |
| 로그인 → 첫 질문 제출 | 30-50% | 45% | 60% |
| 질문 제출 → 답변 완료 | 70-90% | 85% | 92% |
| 답변 완료 → 인용 열기 | 20-40% | 30% | 45% |
| 무료 한도 도달 → 업그레이드 클릭 | 5-15% | 8% | 15% |
| 업그레이드 클릭 → 결제 완료 | 20-40% | 30% | 45% |

### 2.2 핵심 KPI

| 지표 | 정의 | 타겟 |
|------|------|------|
| 활성화율 | 로그인 후 7일 내 답변 완료 + 인용 열기 | 40% |
| Day-7 리텐션 | 가입 후 7일차 재방문 | 25% |
| Free→Pro 전환율 | 무료 가입자의 Pro 업그레이드 비율 (30일) | 5% |
| 월간 활성 사용자 비율 | 가입자 중 월 1회 이상 질문 제출 | 50% |

## 3. 홈페이지 CRO 전략

### 3.1 히어로 섹션 최적화

**현재 구조:**
```
아이브로: "회사 보고서에서 찾은 답의 단서"
H1: "근거가 보이는" + "기업 분석 AI" (accent)
서브텍스트: 긴 설명
데모 폼: 애니메이션
워크플로우 스텝: 3단계
```

**개선안 A — 투자자 잡 중심:**

```
아이브로: "SEC 공시 기반 기업 리서치 AI"
H1: "10-K를 다 읽기 전에"
H1 accent: "근거를 먼저 확인하세요"
서브텍스트: "질문하면 공시 원문에서 근거를 찾아 답변합니다.
            실적 동인, 리스크, 세그먼트 흐름을 한 화면에서 확인."
CTA: [무료로 첫 분석 시작]  [지원 회사 보기]
소셜 프루프 라인: "무료 분석 10회/월 · Google 계정으로 바로 시작"
```

**개선안 B — 차별화 강조:**

```
아이브로: "근거 경로가 남는 기업 공시 리서치"
H1: "AI 답변의 출처를"
H1 accent: "직접 확인하세요"
서브텍스트: "일반 챗봇과 다릅니다. 답변마다 공시 원문 근거 경로가
            남아 검증이 빠릅니다."
CTA: [무료로 첫 분석 시작]
소셜 프루프: "출처 확인 · 공시 원문 · 근거 경로"
```

**히어로 최적화 원칙:**
- 5초 이내에 "이것은 무엇인가" + "왜 다른가"가 전달되어야 함
- H1은 2줄 이내, 서브텍스트는 2문장 이내
- CTA 버튼은 스크롤 없이 보여야 함 (현재 데모 폼 아래에 위치, 명시적 CTA 없음)
- 모바일에서도 CTA가 첫 화면에 노출

### 3.2 CTA 최적화

**1차 CTA: "무료로 첫 분석 시작"**

현재 문제: 홈페이지에 명시적 CTA 버튼이 없음. 데모 폼은 시각적으로 버튼처럼 보이지만 실제로는 로그인/가입으로 연결되지 않음.

**해결책:**
- 데모 폼 아래에 명시적 CTA 버튼 추가
- CTA → `/login?next=/chat` 으로 연결
- 버튼 스타일: `bg-primary` 풀 컬러, 큰 패딩, 명확한 텍스트
- 비활성화 상태 없음: 항상 클릭 가능

**CTA 카피 대안 (A/B 테스트 후보):**

| 순위 | 카피 | 근거 |
|------|------|------|
| 1 | 무료로 첫 분석 시작 | 가치 + 무료 강조, 행동 유도 |
| 2 | 질문으로 분석 시작 | 행동 중심, 제품 경험 반영 |
| 3 | 지금 무료로 시작 | 긴급감 + 무료 |
| 4 | 첫 근거 기반 분석 해보기 | 차별화 강조 |

**2차 CTA: "지원 회사 보기"**

현재 "회사 목록" 버튼이 헤더에 있으나, 가치 제안이 불명확.
"지원 회사 보기"로 변경하여 "내가 관심 있는 회사가 있는지" 확인 가능하게 함.

**CTA 계층 구조:**

```
히어로:     [무료로 첫 분석 시작] (primary, large)
           [지원 회사 보기]       (secondary, outline)
스크롤 중간: [무료로 첫 분석 시작] (sticky 또는 반복)
푸터:       [무료로 첫 분석 시작] (마지막 기회)
```

### 3.3 소셜 프루프 전략

**프리런치 단계 (현재):**
- 고객 증언이나 로고가 없으므로, 대체 소셜 프루프 사용

**사용 가능한 소셜 프루프:**
1. **제품 역량 프루프:** "SEC 공시 기반 근거 경로", "지원 기업 수"
2. **무료 제공 강조:** "무료 분석 10회/월" — 가격 투명성으로 신뢰
3. **보안/기술 신뢰:** "Supabase 인증", "Google SSO"
4. **미디어/커뮤니티:** 런치 후 누적

**소셜 프루프 배치:**

| 위치 | 내용 | 형태 |
|------|------|------|
| 히어로 CTA 아래 | "무료 분석 10회/월 · Google 계정으로 바로 시작" | 텍스트 라인 |
| 히어로 아래 섹션 | 사용자 언어 인용: "AI 요약은 빠른데 근거를 못 믿겠다" → 해결 | 인용 카드 |
| 증거 경로 섹션 | "출처 확인 · 공시 원문 · 근거 경로" | 키워드 배지 |
| 가격 섹션 | "무료로 시작, 분석이 가치 있으면 업그레이드" | 카피 |

**런치 후 소셜 프루프 로드맵:**
1. Phase 1 (0-2개월): 사용자 수 공개 안 함, 대체 프루프 사용
2. Phase 2 (2-4개월): 초기 사용자 인용 3-5개 수집, 승인 후 게시
3. Phase 3 (4-6개월): 사용자 수, 분석 건수 등 정량 지표 공개

### 3.4 신뢰 신호 및 오브젝션 핸들링

**필수 신뢰 신호:**

1. **투자 조언 면책:** 답변 영역 근처에 "투자 조언이 아닌 리서치 도구입니다" 명시
2. **출처 투명성:** "모든 답변은 공시 원문에서 출발합니다" 배너
3. **데이터 보호:** "질문 내용은 분석 외 목적으로 사용하지 않습니다"
4. **무료 투명성:** "무료 10회, 카드 없이 시작" 명확 표시

**오브젝션 핸들링 매트릭스:**

| 이견 | 대응 위치 | 대응 메시지 |
|------|----------|------------|
| "일반 챗봇과 다른가?" | 히어로 서브텍스트 | "공시 원문에서 근거를 찾아 답변합니다. 출처가 보이는 리서치." |
| "비싸지 않은가?" | 가격 근처 | "무료 분석 10회로 시작하세요. 가치를 먼저 경험하고 결정하세요." |
| "어떤 회사가 되나?" | 지원 회사 CTA | "지원 회사 보기에서 확인 후 시작하세요." |
| "투자 조언인가?" | CTA 근처 푸터 노트 | "투자 조언이 아닌, 근거 기반 리서치 도구입니다." |
| "AI가 틀리면?" | 증거 경로 섹션 | "근거 경로로 출처를 직접 확인하세요. 판단은 항상 투자자의 몫입니다." |
| "무엇을 물어봐야 하나?" | 채팅 빈 상태 | "추천 질문으로 시작: 실적 동인, 리스크 요인, 세그먼트 분석" |

### 3.5 모바일 최적화

**현재 문제:**
- 헤더 로그인 버튼이 `hidden sm:inline-flex`로 모바일에서 숨김
- 히어로 H1이 모바일에서 `text-[44px]`로 적절
- 데모 폼이 모바일에서도 잘 작동
- 트레이스 익스플로러가 좁은 화면에서 레이아웃 압축

**개선안:**
1. 모바일 헤더에 "시작하기" 버튼 추가 (햄버거 메뉴 대신 또는 추가)
2. 모바일 CTA를 화면 하단에 sticky 배치
3. 트레이스 익스플로러를 모바일에서 세로 스택으로 전환
4. 히어로 폴드를 짧게 유지: CTA가 첫 화면에 반드시 노출

## 4. 페이지별 CRO 전략

### 4.1 홈페이지 (/)

**목표:** 콜드 방문자를 5초 이내에 이해시키고 CTA로 유도

**페이지 구조 개선안:**

```
1. 히어로 (above the fold)
   - 아이브로 + H1 + 서브텍스트 + CTA
   - 데모 폼 → 실제 CTA 버튼으로 교체

2. 근거 경로 설명 (현재 Trace Card 위치)
   - "질문 → 근거 → 연결 → 답변" 흐름 시각화
   - 실제 AMZN 예시로 데모

3. 사용 사례 3가지
   - 실적 동인 분석
   - 리스크 요인 확인
   - 투자 thesis 검증

4. 소셜 프루프 / 신뢰 섹션
   - "투자자들이 묻는 질문" 인용 카드
   - 보안/면책 배지

5. 지원 회사 + 마무리 CTA
   - 대표 티커 로우 (AAPL, AMZN, NVDA, GOOGL, MSFT 등)
   - [무료로 첫 분석 시작]
```

### 4.2 회사 목록 페이지 (/companies)

**목표:** 지원 기업 확인 후 바로 분석 시작

**개선안:**
- 각 회사 카드에 "이 회사 분석하기" CTA 추가
- 카테고리 필터: 섹터, 시가총액 범위
- 검색 기능 상단 배치
- 비로그인 사용자에게 "로그인하고 분석 시작" 프롬프트
- 회사 카드에 최근 분석 질문 예시 표시

### 4.3 가격 페이지 (/pricing) — 신규 구축

**목표:** 무료→Pro 업그레이드 의사 결정 지원

**핵심 요소:**

```
히어로: "분석이 가치로운 만큼만"
         "무료 10회로 시작, 더 필요하면 Pro로"

플랜 비교 테이블:
┌──────────┬──────────┬──────────┬──────────┐
│          │ Free     │ Pro      │ Power    │
│ 가격      │ ₩0/월    │ ₩29,000 │ ₩69,000  │
│ 분석 수   │ 10회/월  │ 100회/월 │ 300회/월 │
│ 추천      │          │ ★추천    │          │
└──────────┴──────────┴──────────┴──────────┘

FAQ:
- 무료 한도가 되면 어떻게 되나요?
- 결제는 어떻게 하나요?
- 언제든 해지 가능한가요?
- 환불 정책은?
```

**가격 페이지 CRO 원칙:**
- Pro 플랜을 시각적으로 강조 (추천 배지, 테두리 강조)
- "가장 인기" 또는 "대부분의 투자자에게 적합" 라벨
- 월간 분석 수를 기준으로 "나에게 맞는 플랜 찾기" 가이드
- 연간 결제 옵션은 2개월 무료로 표시
- 무료 플랜에 "신용카드 없이" 강조

### 4.4 유스케이스 페이지 (/use-cases/*)

**목표:** SEO 유입 트래픽을 가입으로 전환

**페이지별 구조:**

```
/use-cases/filing-analysis:
  H1: "10-K·10-Q를 AI로 분석하는 방법"
  문제 → 해결 → KRW Ontology로 하는 방법 → 예시 → CTA

/use-cases/thesis-check:
  H1: "투자 thesis를 공시 근거로 검증하기"

/use-cases/risk-factor-analysis:
  H1: "기업 리스크 요인을 근거와 함께 분석"
```

**CRO 요소:**
- 각 페이지에 인라인 CTA: "이 분석 직접 해보기"
- 관련 예시 질문 3-5개 표시
- 관련 회사 페이지로 내부 링크

### 4.5 회사 개별 페이지 (/companies/[ticker])

**목표:** 특정 기업 관심 트래픽을 분석 시작으로 전환

**구조:**
```
히어로: "{회사명} ({TICKER}) 공시 리서치"
서브: "{회사명}의 실적 동인, 리스크, 세그먼트를 근거와 함께 분석"
추천 질문 5개:
  - "{TICKER} 매출 성장 요인은?"
  - "{TICKER} 주요 리스크는?"
  - "{TICKER} 세그먼트별 수익성은?"
CTA: [무료로 {회사명} 분석 시작]
지원 회사 네비게이션: 인접 섹터 회사 링크
```

### 4.6 블로그 (/blog)

**CRO 요소:**
- 각 포스트 하단에 관련 유스케이스 페이지 CTA
- 사이드바에 "무료 분석 10회" 배너
- 이메일 구독 폼 (리드 마그넷 연계)

## 5. 퀵 윈 (즉시 구현)

### 5.1 우선순위 높은 개선

## 6. 고임팩트 변경 (우선 구현)

### 6.1 히어로 섹션 리라이트

**개선 전:**
```
아이브로: 회사 보고서에서 찾은 답의 단서
H1: 근거가 보이는 / 기업 분석 AI
서브: 궁금한 회사를 질문하면, 회사 보고서에서 답의 단서를 찾아
      근거를 바탕으로 정리합니다. 실적 변화, 리스크, 사업 흐름을
      더 쉽게 확인하세요.
```

**개선 후:**
```
아이브로: SEC 공시 기반 기업 리서치 AI
H1: 10-K를 다 읽기 전에 / 근거를 먼저 확인하세요
서브: 질문하면 공시 원문에서 근거를 찾아 답변합니다.
      실적 동인, 리스크, 세그먼트 흐름을 한 화면에서 확인.
CTA: [무료로 첫 분석 시작]
프루프: 무료 분석 10회/월 · Google 계정으로 바로 시작
```

### 6.2 사용 사례 섹션 신규 추가

히어로 아래에 3개 카드 배치:

**카드 1: 실적 동인 분석**
- 아이콘: trending_up
- 제목: "매출·이익 변화의 이유를 근거와 함께"
- 예시 질문: "NVDA 데이터센터 성장 요인을 최근 공시 기준으로 분해해줘"
- CTA: "이 분석 해보기"

**카드 2: 리스크 요인 확인**
- 아이콘: shield
- 제목: "공시 원문에서 리스크를 연결해서 보기"
- 예시 질문: "AAPL 서비스 매출 리스크가 어느 사업 활동과 연결되는지 보여줘"
- CTA: "이 분석 해보기"

**카드 3: 투자 Thesis 검증**
- 아이콘: fact_check
- 제목: "투자 아이디어를 공시 근거로 검증"
- 예시 질문: "AMZN 클라우드 이익률이 왜 바뀌었는지 근거와 함께 정리해줘"
- CTA: "이 분석 해보기"

## 7. A/B 테스트 후보

### 7.1 히어로 테스트

| 테스트 | 가설 | 1차 지표 | 2차 지표 |
|--------|------|---------|---------|
| H1 카피 A vs B | "근거가 보이는 기업 분석 AI" vs "10-K를 다 읽기 전에 근거를 먼저 확인하세요" | CTA 클릭률 | 로그인 완료율 |
| CTA 카피 A vs B | "무료로 첫 분석 시작" vs "질문으로 분석 시작" | CTA 클릭률 | 첫 질문 제출률 |
| 히어로 이미지 vs 데모 | 정적 스크린샷 vs 현재 애니메이션 데모 | 체류시간 | CTA 클릭률 |
| 소셜 프루프 유무 | "무료 10회/월" 텍스트 vs 없음 | CTA 클릭률 | 이탈률 |

### 7.2 가격 페이지 테스트

| 테스트 | 가설 | 1차 지표 |
|--------|------|---------|
| Pro 플랜 강조 방식 | "추천" 배지 vs "가장 인기" 배지 | Pro 선택률 |
| 가격 표시 | 월간만 vs 월간+연간(2개월 무료) | 연간 선택률 |
| 무료 플랜 설명 | "10회 무료" vs "신용카드 없이 시작" | 가입 시작률 |

### 7.3 회사 페이지 테스트

| 테스트 | 가설 | 1차 지표 |
|--------|------|---------|
| 추천 질문 수 | 3개 vs 5개 | 질문 제출률 |
| CTA 카피 | "분석 시작" vs "{회사명} 근거 분석하기" | CTA 클릭률 |

## 8. 측정 및 모니터링

### 8.1 필수 이벤트 추적

CRO 개선 효과를 측정하기 위해 다음 이벤트가 필수:

```
home_viewed          → 홈페이지 방문
cta_clicked          → CTA 클릭 (cta_id, cta_label 포함)
login_started        → 로그인 시작
login_completed      → 로그인 완료
question_submitted   → 첫 질문 제출
answer_completed     → 답변 완료
citation_opened      → 인용/근거 열기
limit_reached        → 무료 한도 도달
upgrade_clicked      → 업그레이드 클릭
subscription_started → 결제 완료
```

### 8.2 대시보드 구성

**퍼널 대시보드 (일간):**
```
방문자 → CTA 클릭 → 로그인 → 질문 → 답변 → 인용 → 업그레이드
각 단계 전환율 + 전일/전주 대비
```

**페이지 성과 대시보드 (주간):**
```
각 페이지별: 방문수, 이탈률, 체류시간, CTA 클릭률
소스별: organic, direct, referral, social, email
디바이스별: desktop, mobile, tablet
```

**실험 대시보드:**
```
실험명 | 노출수 | 전환수 | 전환율 | 신뢰도 | 개선율
```

## 11. 요약

CRO 전략의 핵심은 **"5초 안에 근거 기반 리서치 AI임을 전달하고, 무료로 바로 시작할 수 있게 하는 것"**이다.

**최우선 실행 3가지:**
1. 명시적 CTA 버튼 추가 (현재 없음 → 가장 큰 개선 기회)
2. 히어로 카피를 투자자 잡 중심으로 재작성
3. "무료 분석 10회" 가격 투명성 추가

**성공 기준:**
- 홈페이지 → CTA 클릭률 5% 달성 (3개월 내)
- 활성화율 40% 달성 (3개월 내)
- Free→Pro 전환율 5% 달성 (6개월 내)
