# 팝업/인앱 메시지 전략

*최종 수정: 2026-05-23*

---

## 1. 전략 개요

### 1.1 원칙

- **비침습적:** 팝업은 사용자 경험을 방해하지 않아야 함
- **맥락 기반:** 사용자 행동과 상태에 맞는 메시지
- **가치 우선:** 메시지가 사용자에게 실제 가치를 제공해야 함
- **빈도 제한:** 사용자당 일/주 단위 노출 한도 설정
- **쉬운 닫기:** 모든 팝업/배너는 1클릭으로 닫기 가능

### 1.2 메시지 유형 분류

| 유형 | 형태 | 침습도 | 사용 기준 |
|------|------|--------|----------|
| 토스트 | 하단/상단 슬라이드업 | 낮음 | 정보성 알림 |
| 배너 | 페이지 상단/하단 고정 | 낮음 | 지속적 안내 |
| 인라인 | 콘텐츠 내 자연스러운 배치 | 낮음 | 맥락 제안 |
| 슬라이드인 | 화면 측면에서 슬라이드 | 중간 | 제안/프롬프트 |
| 모달 | 화면 중앙 오버레이 | 높음 | 중요 결정만 |

### 1.3 노출 빈도 규칙

| 규칙 | 설정 |
|------|------|
| 동일 메시지 일 최대 | 1회 |
| 모달 일 최대 | 1회 |
| 슬라이드인 일 최대 | 2회 |
| 토스트/배너 | 제한 없음 (항상 닫기 가능) |
| 닫은 메시지 재노출 | 7일 후 |
| 전환 완료 후 | 동일 메시지 미노출 |

## 4. 구현 가이드

### 4.1 메시지 상태 관리

```typescript
interface InAppMessage {
  id: string;
  type: 'toast' | 'banner' | 'slide-in' | 'inline' | 'modal';
  trigger: Trigger;
  content: MessageContent;
  frequency: Frequency;
  dismissible: boolean;
}

interface Trigger {
  event?: string;        // 이벤트 이름
  scrollDepth?: number;  // 스크롤 %
  timeOnPage?: number;   // 체류 시간 (초)
  exitIntent?: boolean;  // 이탈 의도
  cohort?: string;       // 코호트 조건
}

interface Frequency {
  maxPerSession: number;
  maxPerDay: number;
  maxPerWeek: number;
  cooldownAfterDismiss: number; // 시간
}

interface MessageContent {
  title: string;
  body: string;
  ctaLabel: string;
  ctaAction: string;   // URL 또는 액션
  dismissLabel?: string;
  variant?: string;    // A/B 테스트용
}
```

### 4.2 노출 추적

```sql
-- message_impressions 테이블
message_impressions (
  id          UUID PRIMARY KEY,
  user_id     UUID REFERENCES auth.users(id),
  anonymous_id TEXT,
  message_id  TEXT NOT NULL,
  action      TEXT NOT NULL,  -- 'shown', 'clicked', 'dismissed'
  variant     TEXT,
  created_at  TIMESTAMPTZ NOT NULL
)
```

### 4.3 프런트엔드 구현 원칙

1. **단일 메시지 매니저:** 모든 메시지를 중앙에서 관리 (동시 노출 방지)
2. **우선순위 큐:** 모달 > 슬라이드인 > 배너 > 토스트 순서
3. **노출 규칙 엔진:** 빈도, 코호트, 세션 상태 기반 필터링
4. **애니메이션:** `motion/react`로 부드러운 등장/사라짐
5. **접근성:** `aria-live`, `role="dialog"` (모달), 포커스 트랩

| 5초 이내 첫 팝업 | Google 페널티 가능성 (모바일) | 첫 팽 Korean Content 후 노출 |
| 닫기 버튼 숨김 | 사용자 분노, 이탈 | 항상 명확한 닫기 |
| 같은 메시지 반복 | 배너 맹목 (banner blindness) | 빈도 제한 |
| 모바일 전체화면 팝업 | Google 인터스티셜 페널티 | 배너/슬라이드인만 |

### 6.2 법적 고지

- 이메일 수집 시: 개인정보처리방침 링크 포함
