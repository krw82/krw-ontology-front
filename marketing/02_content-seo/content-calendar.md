## 1. 콘텐츠 전략 개요

### 1.1 콘텐츠 미션

한국어 사용 투자자가 "미국 기업 공시를 어떻게 분석하나요?"에서 시작해 KRW Ontology를 자연스럽게 발견하고 가입하는 경로를 만드는 콘텐츠.

### 1.2 콘텐츠 원칙

1. **교육 우선, 제품은 자연스럽게** — 공시 분석 방법을 가르치고, 도구는 맥락에서 소개
2. **근거 기반** — 모든 주장에 공시 출처, 구체적 예시 첨부
3. **AI 검색 최적화** — 질문-답 구조, 직접 정의, 한국어+영문 병기
4. **투자 권유 금지** — 정보 제공과 리서치 보조에 집중

### 1.3 콘텐츠 포맷

| 포맷 | 용도 | 발행 주기 | 길이 |
|------|------|-----------|------|
| 블로그 글 | SEO, 교육, AI 검색 진입 | 주 1편 | 1,500-3,000자 |
| 유스케이스 페이지 | 제품 소개, 전환 | 필요시 | 800-1,500자 |
| 회사 랜딩페이지 | 프로그래매틱 SEO | 배치 | 500-1,000자 |
| 질문 템플릿 | 제품 체험, SEO | 격주 | 300-500자 |
| 뉴스레터 | 리텐션, 리마인드 | 격주 | 500-800자 |
| 소셜 포스트 | 인지도, 트래픽 | 주 2-3회 | 100-300자 |

## 3. 블로그 글 템플릿

### 3.1 교육형 글 (How-To / Guide)

```markdown
# {질문 형태 제목} — 예: "10-K에서 리스크 요인을 찾는 방법"

## TL;DR
{3문장 요약 — AI 검색에서 인용 대상}

## {개념 설명}
{배경 지식, 공시에서의 위치, 왜 중요한지}

## {실전 방법}
1. {단계 1 — 구체적 설명}
2. {단계 2 — 구체적 설명}
3. {단계 3 — 구체적 설명}

## {실제 예시}
{구체적 회사 사례, 공시 섹션 인용}

## {한계 및 주의사항}
- 이 가이드는 정보 제공 목적이며 투자 권유가 아닙니다
- {구체적 한계}

## 관련 질문
- {내부 링크: 관련 질문 템플릿}
- {내부 링크: 관련 회사 페이지}
```

### {포인트 1}

### {포인트 2}
{공시 인용문 + 해석}

2. **경쟁사 분석** — 상위 5개 결과의 구조와 포맷 확인
3. **아웃라인 작성** — 헤딩 구조, 내부 링크 계획
4. **초안 작성** — 템플릿에 맞춰 작성
5. **SEO 체크** — 제목(50-60자), 설명(150-160자), 헤딩 키워드 포함
6. **AI 검색 체크** — 첫 문장에 직접 정의 포함, 질문-답 구조
7. **내부 링크** — 관련 회사/유스케이스/질문 템플릿 링크 3개 이상
8. **발행 후 공유** — 소셜 포스트, 뉴스레터(해당 시)
