## 1. 브랜드 보이스

### 1.1 톤앤매너

**기본 톤:** 전문적, 정확, 차분, 근거 중심

| 특성 | 설명 | 예시 |
|------|------|------|
| 전문적 | 금융/투자 도메인 전문성을 보여줌 | "10-K Item 1A 리스크 요인 섹션에서..." |
| 정확 | 구체적 사실과 출처 중심 | "2025년 10-K 기준, AWS 매출은 전체 매출의 17%를 차지합니다." |
| 차분 | 과장 없이 사실 전달 | "~입니다" 체, 감탄사 최소화 |
| 근거 중심 | 주장에 출처를 항상 동반 | "SEC 공시 원문 기반 / 10-K p.45 인용" |

### 1.2 금지 표현

| 금지 | 이유 | 대체 |
|------|------|------|
| "정확한 예측" | 과장, 투자 권유 오해 | "공시 기반 분석" |
| "수익 보장" | 규제 위반 | "리서치 보조 도구" |
| "AI가 완벽하게" | 신뢰 훼손 위험 | "공시 원문에서 근거를 찾아 답변" |
| "최고의", "유일한" | 근거 없는 우위 주장 | "근거 경로가 남는", "출처 확인 가능한" |
| "혁명적", "게임 체인저" | 과장된 마케팅 톤 | "공시 분석 워크플로우 개선" |
| "무조건 정확" | 책임 문제 | "근거를 확인할 수 있는" |
| 감탄사 남용 (!!!) | 전문성 훼손 | 마침표로 문장 종결 |

### 1.3 권장 표현

| 상황 | 권장 표현 |
|------|-----------|
| 제품 소개 | "근거 경로가 남는 기업 공시 리서치 AI" |
| 핵심 가치 | "출처를 확인할 수 있는 답변" |
| 차별점 | "공시 원문 근거와 함께 답변합니다" |
| 기능 설명 | "질문하면, 공시에서 근거를 찾아 정리합니다" |
| 신뢰 | "답변은 공시 문장에서 시작됩니다" |
| CTA | "무료로 첫 분석 시작" |

## 2. 메시지 계층

### 2.1 메시지 피라미드

```
            [핵심 메시지]
     "근거 경로가 남는 기업 공시 리서치 AI"
            /              \
    [가치 제안]          [차별화]
  "질문하면 공시에서     "출처 확인 가능한
   근거를 찾아 답변"      근거 경로 제공"
      /          \           /          \
  [기능]       [혜택]    [신뢰]       [편의]
  - 질문 입력   - 시간    - 출처      - 한국어
  - 근거 탐색     절약     공개        우선
  - 답변 정리   - 검증    - 원문      - 질문
                용이      인용         템플릿
```

### 2.2 메시지 계층별 가이드

**핵심 메시지 (10초 이내 전달):**
> 근거 경로가 남는 기업 공시 리서치 AI. 질문하면, 공시에서 근거를 찾아 정리합니다.

**가치 제안 (30초 이내 전달):**
> 긴 10-K를 다 읽기 전에, 먼저 투자 질문의 근거를 확인하세요. 답변마다 공시 원문 출처가 남습니다.

**차별화 (1분 이내 전달):**
> 일반 AI는 요약만 하지만, KRW Ontology는 공시 문장에서 시작해 사업 맥락과 리스크를 연결합니다. 모든 답변에 근거 경로가 포함됩니다.

## 7. 카피 품질 체크리스트

모든 카피 발행 전 확인:

- [ ] 투자 권유 표현이 없는가?
- [ ] "정확", "완벽", "보장" 등 과장 표현이 없는가?
- [ ] 근거/출처/공시 관련 용어가 포함되어 있는가?
- [ ] CTA가 명확한가? ("무료로 첫 분석 시작")
- [ ] 감탄사가 1개 이하인가?
- [ ] "투자 권유 아님" 면책이 필요한 위치에 있는가?
- [ ] 한국어 문법이 자연스러운가? (번역투 지양)
- [ ] 금융/투자 용어가 정확한가?
- [ ] 제품 카테고리가 명확한가? ("기업 공시 리서치 AI")
