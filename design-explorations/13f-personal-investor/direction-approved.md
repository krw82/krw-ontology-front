# Approved direction — 2026-07-26

## 선택

사용자가 **방향 2 · Quarterly Story**를 선택했다.

## 선택 이유

- 개인투자자가 13F를 처음 읽을 때 가장 자연스럽게 “이번 분기에 무엇이 달라졌나”부터 이해할 수 있다.
- 390px 모바일에서 좌우 비교나 복잡한 바둑판을 강요하지 않고, 변화 → 핵심 보유 → 전체 보유라는 세로 읽기 흐름을 유지한다.
- 기준일, SEC 13F, 직전 분기 비교라는 공시 맥락을 별도 레일/요약으로 계속 보여 주어 신뢰를 잃지 않는다.

## 구현에서 지킬 것

1. 기존의 실제 dashboard 데이터와 검색 기능을 유지한다. 시안의 숫자는 새 데이터 모델을 요구하지 않는다.
2. 첫 화면은 변화 요약을 읽는 구조로 바꾸되, 상세 보유는 비교가 쉬운 표/목록으로 남긴다.
3. 모바일에서는 공시 메타데이터를 2열 요약으로, 증감 종목은 한 행씩, 상위 보유는 회사명 중심의 목록으로 보여 준다.
4. 색상만으로 증감을 표현하지 않고 ‘비중 증가/감소’와 +/- %p를 함께 쓴다.
5. 원문 13F와 현재 보유의 차이를 설명하는 주석을 화면에 남긴다.
