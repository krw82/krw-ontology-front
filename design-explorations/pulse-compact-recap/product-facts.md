# Pulse compact recap · working facts

> Checked: 2026-07-26 (KST)
> Scope: a direction prototype only; this file does not define production behavior.

## Product context

- **KRW.O** is the existing local product in this repository. The current mobile Pulse screen is captured at `../../.lazyweb/design-improve/pulse-2026-07-26/references/current-mobile.png`.
- The current implementation uses large, repeated `PulseCard` containers with a coloured left rail and a primary CTA. The prototype deliberately tests the opposite treatment: an editorial, compact event feed.
- The only content shown in the prototypes is labelled as sample data. It must not be read as an actual filing, trade, recommendation, or company fact.

## Reference context

- [Quartr Daily & weekly recaps](https://quartr.com/features/daily-and-weekly-recaps) describes recaps around followed companies, recent events, short summaries, and direct links into source material.
- The reference is used for **density, calm hierarchy, and event-first recap rhythm**. It is not copied as a visual template and it does not prescribe KRW.O’s data model.

## Prototype decision boundaries

- One compact feed replaces many large cards; this is a visual exploration, not a deletion of existing Pulse item types.
- The final product should continue to distinguish source evidence, user research context, and urgency. The prototypes use text hierarchy rather than decorative rails, badges, and CTA blocks to do that.
