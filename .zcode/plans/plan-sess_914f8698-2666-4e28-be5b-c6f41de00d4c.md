## 근본 원인

`dev-with-worker.mjs`의 `shutdown()` → `stopChild(devMcp)`가 `uv` 프로세스에만 SIGTERM/SIGKILL을 보냄. 하지만 `start-mcp-server-dev.sh:82`의 `exec uv run krw-ontology-mcp`는 내부적으로 `python3`를 별도 프로세스로 spawn하므로, `uv`가 죽어도 `python3`가 8766 포트를 붙잡은 채 살아남음 → 좀비 프로세스 발생 → 다음 `npm run dev` 시 포트 충돌.

## 수정 — 포트 기반 cleanup (stock-news-mcp 검증 패턴 복제)

`stopManagedStockNewsListener()`(655–677줄)와 동일한 패턴을 dev MCP에도 적용.

### 수정 파일: `scripts/dev-with-worker.mjs`

**1. 새 함수 `stopManagedDevMcpListener()` 추가** (`stopManagedStockNewsListener` 바로 뒤)

stock-news-mcp 패턴과 동일하게:
- 8766 포트를 LISTEN 중인 PID들을 lsof로 수집
- 각 PID의 command를 확인해 `krw-ontology-mcp` 또는 `krw-ontology` 관련 프로세스인지 검증 (안전장치 — 무관한 프로세스 kill 방지)
- SIGTERM 전송

```js
function stopManagedDevMcpListener() {
  const port = new URL(process.env.KRW_ONTOLOGY_MCP_URL).port || "8766";
  const result = spawnSync("lsof", ["-nP", `-tiTCP:${port}`, "-sTCP:LISTEN"], {
    encoding: "utf8",
  });
  const pids = result.stdout
    .split(/\s+/)
    .map((pid) => pid.trim())
    .filter(Boolean);
  for (const pid of pids) {
    const command = spawnSync("ps", ["-p", pid, "-o", "command="], {
      encoding: "utf8",
    }).stdout;
    if (
      !command.includes("krw-ontology-mcp") &&
      !command.includes("krw-ontology") &&
      !command.includes("uv")
    ) {
      throw new Error(`Port ${port} is occupied by an unmanaged process: pid=${pid}`);
    }
    try {
      process.kill(Number(pid), "SIGTERM");
    } catch {
      // Process may have exited between lsof and kill.
    }
  }
}
```

**2. `shutdown()` 함수에 호출 추가** (737–752줄)

`stopChild(devMcp)` 앞이나 뒤에 `stopManagedDevMcpListener()` 호출. 동기 함수이므로 `Promise.allSettled` 배열에 직접 넣지 않고 호출.

```js
async function shutdown(signal) {
  if (shuttingDown) return;
  shuttingDown = true;
  console.info(`[dev] shutting down after ${signal}`);

  try {
    stopManagedDevMcpListener();
  } catch (error) {
    console.warn(`[dev:mcp] cleanup warning: ${error.message}`);
  }

  await Promise.allSettled([
    workerContext?.dispose(),
    documentWorkerContext?.dispose(),
    stopChild(worker),
    stopChild(documentWorker),
    stopChild(devMcp),
    stopChild(stockNewsMcp),
    stopChild(feedMcp),
    stopChild(nextDev),
  ]);
}
```
