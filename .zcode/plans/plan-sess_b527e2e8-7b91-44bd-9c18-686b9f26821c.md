## 티커 없는 와이드 리서치를 Pulse "방금 완료" 란에 표시

### 배경

현재 Pulse의 "방금 완료"/"진행 중" 란은 `scope_type = "company"` 세션만 수집합니다 (`analysis.ts:46`). 매크로 이슈에서 시작한 `idea_generation` 리서치는 `scope_type: "global"` 세션으로 생성되므로 Pulse에 나타나지 않습니다.

데이터 플로우는 이미 `ticker: null` 에 대해 null-safe 입니다 (Zod 스키마, PulseItemBase, composer 필터, UI 렌더링 모두 nullable). 따라로 쿼리 범위만 넓히면 자연스럽게 흘러갑니다.

### 수정 파일 (3개)

#### 1. `src/lib/pulse/sources/analysis.ts` — 쿼리 범위 확장

**라인 46**: `.eq("scope_type", "company")` → `.in("scope_type", ["company", "global"])`

```diff
-    .eq("scope_type", "company")
+    .in("scope_type", ["company", "global"])
```

#### 2. `src/lib/pulse/sources/analysis.ts` — 글로벌 리서치용 복사 분기

`buildAnalysisCandidates` (라인 104-145)에서 `ticker`가 `null`이면 글로벌 리서치용 텍스트를 사용하도록 분기:

- `eyebrow`: "내가 시작한 분석 · 진행 중/완료" → 글로벌: "와이드 리서치 · 진행 중/완료"  
- `reason_label`: "회사 채팅에서 직접 시작한..." → 글로벌: "매크로/와이드 리서치로 시작한 분석의 저장된 상태입니다."
- `metadata`에 `scope_type: "global"` 추가 (UI에서 아이콘 분기용)

#### 3. `src/lib/pulse/sources/analysis.ts` — `buildChatSessionHref`에 runKind 전달

글로벌 세션의 링크에 `runKind=idea_generation` 파라미터를 추가하여 chat 페이지에서 올바른 모드로 열리도록:

```diff
-    const href = buildChatSessionHref(session.id, { ticker });
+    const href = buildChatSessionHref(session.id, {
+      ticker,
+      runKind: ticker ? null : "idea_generation",
+    });
```

### UI fallback (이미 존재 — 별도 수정 불필요)

`PulseFeed.tsx`의 `CompletedResearchRow`는 이미 `ticker: null` 케이스를 처리합니다:
- 회사 로고 자리에 `K` 배지 표시
- 회사 페이지 링크 없음 (채팅 링크만)
- 회사명 대신 `"KRW.O"` 폴백

이 폴백이 동작하긴 하지만, 글로벌 리서치에 더 맞는 표시(예: `📊` 아이콘, "와이드 리서치" 라벨)로 개선하는 것은 별도 작업으로 두고, **이번에는 데이터 표시만 활성화**하는 최소 변경으로 진행합니다.

### 테스트

`src/lib/pulse/sources/analysis.test.ts` (신규 또는 기존 확장)에 다음 케이스 추가:
- `scope_type: "global"`, `default_tickers: []` 세션의 completed run → candidate 생성됨 (`ticker: null`, `eyebrow`에 "와이드 리서치")
- `scope_type: "company"` 세션은 기존대로 동작 (회귀 없음)

### 동작 흐름

```
매크로 이슈 → idea_generation 리서치 완료
  ↓
chat_sessions: scope_type="global", default_tickers=[]
  ↓
Pulse analysis.ts: .in("scope_type", ["company","global"]) → 이제 수집됨
  ↓
buildAnalysisCandidates: ticker=null → "와이드 리서치 · 완료" eyebrow
  ↓
PulseFeed.tsx: CompletedResearchRow → K 배지 + 채팅 링크로 표시
```
